# ملفات Photoshop — تصدير التوافق v2

هذه نسخ بديلة للملفات القديمة التي رفض Photoshop فتحها. كل ZIP أدناه يحتوي ملف PSD حقيقيًا، منفصلًا لكل شخصية، وليس حزمة صور Sources.

**الخطوات:** حمّلي ZIP، اختاري استخراج الكل / Extract All، ثم من Photoshop اختاري File → Open وافتحي ملف `.psd` الموجود داخله.

أُعيد فتح الملفات وتصديرها وحفظها وفتحها مجددًا باستخدام GIMP3.0.4 ومصدّر PSD الأصلي، مع الحفاظ على أسماء الطبقات وترتيبها وظهورها وألوانها. كل طبقات الصور وبيانات المعاينة تستخدم RLE التقليدي، بدل ZIP Prediction في التصدير السابق.

فُحصت ملفات PSD كذلك باستخدام psd-tools وPillow، وفُحص تطابق الشكل مع النسخة المعتمدة. لم تُشغّل هذه الملفات داخل Photoshop هنا، لذلك توافق نسخة Photoshop عند المستلمة يحتاج اختبارًا فعليًا لديها. اختبار التحريك والريج ما زال غير منفّذ.

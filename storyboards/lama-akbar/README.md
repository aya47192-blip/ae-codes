# لما أكبر — ستوريبورد للمراجعة

[تحميل الستوريبورد PDF](Lama-Akbar-Storyboard-v01.pdf)

16 صفحة تشمل لوحتين بصريتين غنيتين و12 لقطة تغطي 90 ثانية تقريبًا، مع الكادرات والأداء والحوار المصري والمؤثرات الصوتية والانتقالات والاستمرارية. الشكل مرجع سينمائي ناضج مولد للمراجعة، وليس فيديو نهائيًا. بدون موسيقى أو ترجمة تفسيرية على الشاشة. الحوار خطة أداء صوتي، ولم يُسجّل بعد.

فكي ضغط ZIP الخاص بالزاوية وافتحي ملف PSD بداخله مباشرة. لمصدر After Effects: فكي الحزمة بالكامل ثم شغلي `After-Effects/build_project.jsx` من File > Scripts > Run Script File في مشروع فارغ. التعليمات التفصيلية في [README-AR.md](README-AR.md).

تم حفظ PSD وإعادة فتحه في GIMP وفحصه بقارئ مستقل، واجتازت اختبارات ملكية الأطراف وإخفاء الملابس والملامح وقياسات ثبات القدمين. تم فك ترميز جميع إطارات فيديو المعاينة المحلية (1440 إطارًا). الفيديو معاينة محلية للطبقات، وليس رندر After Effects. تشغيل Photoshop/After Effects الأصلي وإنشاء AEP وفحصه والرندر الأصلي ما زالت معلقة لعدم توفر البرنامجين هنا. لذلك حزمة After Effects هي مصدر بناء وليست AEP مختبرًا مسبقًا.

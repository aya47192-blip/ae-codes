# علامة في الزحمة — مشروع After Effects

[تحميل الحزمة كاملة — ZIP](Alama-After-Effects.zip)

فيلم Cutout مدته 90 ثانية، 8 مشاهد، 1920×1080 عند 24fps. يتضمن 1252 طبقة للمشاهد، تحكمات منفصلة للشخصيات، ومفاتيح للحركة، وخلفيات وعناصر ونصوص عربية قابلة للتعديل.

## التشغيل

1. حمّلي ZIP من الرابط أعلاه باستخدام زر Download raw file، وفكّي ضغط الحزمة بالكامل.
2. ثبّتي الخط الموجود في مجلد fonts.
3. افتحي مشروعًا فارغًا في After Effects، ثم اختاري File → Scripts → Run Script File.
4. اختاري build_project.jsx، وحددي اسمًا جديدًا لحفظ ملف AEP.
5. افتحي Main لتشغيل الفيلم أو تعديل اللقطات.

## ما تحتويه الحزمة

- build_project.jsx: سكربت بناء المشروع داخل After Effects.
- assets: موسيقى ومؤثرات إرشادية أصلية.
- preview-90s.mp4: معاينة متحركة خارجية من نفس بيانات المشهد.
- storyboard.pdf وصور اللقطات وملف الترجمة.
- READ-ME-AR.txt: تعليمات التعديل والفتح بالعربي.
- rig-controls.csv وscene.json ومصادر التوليد ونتائج الفحص.

## حدود التحقق

هذه حزمة بناء وليست ملف AEP محفوظًا مسبقًا. After Effects غير متاح في بيئة التوليد، ولذلك التشغيل والريج والرندر داخل البرنامج ما زالوا غير مختبرين. المعاينة اجتازت فحص المدة والفريمات وفك الفيديو، لكنها ليست رندرًا أصليًا من After Effects. الحوار مكتوب، بدون أصوات مسجلة أو lip-sync. تلامس الأيدي في لقطة الإنقاذ مخبوز من حل حسابي، والريج FK وليس نظام IK تفاعليًا.

تتطلب الحزمة إصدارًا حديثًا يدعم app.fonts.getFontsByPostScriptName. راجعي الخطوط وتشكيل العربي والحركة داخل البرنامج قبل اعتماد النسخة النهائية.

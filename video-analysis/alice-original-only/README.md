# شخصيات وأغراض أليس — الرسومات الأصلية فقط

[تحميل الحزمة المعدلة بدون كوتشينة](Alice_Original_Characters_and_Props_NO_CARDS.zip)

افتحي `01_Original_Characters_Print.html` للشخصيات، و`02_Original_Props_Print.html` لبقية الأغراض. بعد اكتمال تحميل الصور، اختاري طباعة A4 بمقياس 100% أو Save as PDF. أغلقي Headers and footers. الروابط الخارجية مؤقتة؛ احفظي PDF بعد نجاح التحميل.

الحزمة تستبعد كل الكوتشينة وأي عنصر معاد الرسم: لا قطة مستقلة مستكملة، لا طاولة نظيفة مستكملة، لا بطانية أو خلفيات مولدة. الشخصيات والأغراض مأخوذة من نفس كادرات المصدر، والتفريغ يغيّر الخلفية والشفافية فقط. توجد ٨ وضعيات أصلية لأليس، وضعيتان للحيوان الأبيض، رمز الأرنب، وعينا القطة وابتسامتها، ثم ٢٢ لوحة للأغراض الأصلية والستائر.

الأجزاء المخفية لا تُخترع: القطة المحمولة تظل ضمن وضعية أليس، والطاولة تحتفظ بالأغراض الظاهرة عليها. لم نحاول رسم ما وراء اليد أو الزجاجة.

ملفا PDF المرفقان يشملان الأجزاء المتاحة محليًا فقط: عينا القطة وابتسامتها من الكادر 57.10 ثانية، والكأس وستارتا الغلق المستطيلتان. مرجع الشخصيات JPEG للمقارنة وليس ورقة قص مفرغة.

**المتبقي:** قيد شبكة بيئة العمل يمنع تنزيل صور التفريغ الخارجية من Runway، فلم يمكن مراجعة كل الحواف محليًا أو تجميع PDF دائم لكل الشخصيات. ملفات HTML بديل للطباعة من متصفح المستخدم؛ لا ندّعي فحص قص 100% لكل صورة خارجية. الرسم الأصلي وحده لا يكشف تفاصيل الأجزاء المتغطية.

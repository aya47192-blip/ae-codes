تحسين هادئ لمنحنى الإضاءة والتباين، وتشبع +12%، وحدّة خفيفة جدًا. لا إعادة رسم، ولا تغيير لأسلوب التلوين أو خامة الورق، ولا توليد فريمات. التحول من الرمادي للون، ومشهد الليل، والعناوين والتترات والتوقيتات محفوظة. القص يزيل الإطار الأسود وتعليق تيك توك خارج الفيلم.

المقاس576×316، والمدة138.97ثانية، و4169فريم عند30fps. الصوت AAC الأصلي منسوخ دون إعادة ترميز، وتطابقت بصمته الرقمية مع المصدر. MP4 بالدقة الفعلية للفيلم بعد القص؛ لم نسمِّ تكبير الصورة تفاصيل HD جديدة.

## After Effects

**الحزمة تحتوي سكربت JSX لبناء المشروع، وليست ملف AEP محفوظًا مسبقًا.** تطبيق AE غير متاح في بيئة التنفيذ. فكي ZIP كاملًا، ثم داخل After Effects اختاري File > Scripts > Run Script File وشغّلي Build_Hayat_AfterEffects_Project.jsx. ينشئ ويحفظ Hayat_Color_Edit.aep بجوار السكربت، ويحتفظ بالميديا في مجلد media.

- FINAL_READY_TO_EDIT: الفيديو المحسّن، مع طبقة تأثيرات محايدة قابلة للتعديل لإضافة التصحيح أو النصوص أو المونتاج. التعديل الحالي مطبوع داخل MP4.
- SOURCE_CROP_NATIVE: المصدر الأصلي بالقص فقط، بصورة غير هدّامة.
- SOURCE_EDIT_FRESH_GRADE: الأصل المقصوص مع Exposure وHue/Saturation وBrightness/Contrast محايدة لو أردتِ إعادة ضبط اللون من البداية.
- COMPARE: الأصل والنسخة المحسّنة جنبًا إلى جنب.

تركيبات العرض1152×632 تستخدم تكبير200% من الدقة الفعلية. JSX فُحص من ناحية الصياغة، لكنه لم يُختبر داخل AE؛ إنشاء AEP الفعلي يتم على جهازك. هذه نسخة فيديو قابلة للمونتاج والتصحيح، وليست مشروع أنيميشن بطبقات شخصيات مفصولة.

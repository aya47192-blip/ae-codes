# طبقات تعديل من نفس بكسلات الفيديو

[تحميل حزمة تجهيز After Effects](Hayat_Source_Pixel_Layers_AE_Setup.zip?raw=true)

الفيديو المرفق هو ملف الـFinal السابق نفسه حرفيًا، دون إعادة ترميز أو تغيير. السكربت ينشئ داخل After Effects طبقة أصلية كاملة مقفولة، وفوقها نسخًا متزامنة من نفس الميديا في مناطق وتوقيتات مناسبة للخلفيات والعناصر الثابتة. لا توجد رسومات جديدة أو فصل للبنت أو تغيير للحركة أو اللون.

**هذه مناطق للتعديل، وليست طبقات الأنيميشن الأصلية أو عزلًا لحذف العناصر.** عند إخفاء طبقة البيت سيظل البيت في الفيديو الأساسي تحتها. بعض الطبقات تمثل منطقة أو لقطة خلفية كاملة، وليست شكلًا منفصلًا يمكن نقله دون خلفيته.

فكي ZIP ثم شغّلي Build_Hayat_Pixel_Copy_Layers.jsx عبر File > Scripts > Run Script File داخل AE. يحفظ مشروع AEP أصليًا على جهازك؛ لا يوجد AEP محفوظ مسبقًا. يتضمن مرجعًا ومقارنة Difference ينبغي أن تكون سوداء قبل التعديل. يحاول السكربت فحص عينات كاملة الكادر داخل AE، ويعطّل طبقات التعديل إن وجد فرقًا، تاركًا الأصل ظاهرًا. لم يُشغّل AE هنا، فلا يوجد ضمان مسبق لكل إعدادات جهازك.

اختبار النسخ والتراكب المحلي أعطى فرق RGBA صفرًا في العينات، وبصمة الفيديو المرفق غير متغيرة. إعادة تصدير MP4 بضغط فقدي قد تغيّر البكسلات حتى لو المشهد متطابق بصريًا؛ للتطابق الحرفي استخدمي الفيديو المرفق نفسه. التعليمات المفصلة داخل الحزمة.

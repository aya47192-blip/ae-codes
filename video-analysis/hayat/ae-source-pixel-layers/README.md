# تجهيز طبقات AE — تصحيح خطأ القفل

- [السكربت المصحح فقط](Build_Hayat_Pixel_Copy_Layers_FIXED.jsx?raw=true)
- [الحزمة الكاملة المصححة](Hayat_Source_Pixel_Layers_AE_Setup_FIXED.zip?raw=true)

عولج خطأ `Cannot set attribute comment ... because the Layer is locked`: كانت الطبقة تُقفل قبل كتابة ملاحظتها. القفل الآن آخر خطوة بعد الإعدادات والملاحظات وفحص المقارنة وقبل الحفظ. لا تعديل في الفيديو نفسه. لو لديك الفيديو بالفعل، حمّلي السكربت FIXED فقط وشغّليه عبر File > Scripts > Run Script File؛ سيطلب اختيار الفيديو إذا لم يكن بجواره.

أُعيد إنتاج الخطأ القديم في محاكاة لقاعدة قفل الطبقات، والنسخة المصححة أكملت الحفظ في حالتي نجاح فحص المقارنة ومسار التعطيل الآمن. فُحصت الصياغة أيضًا. After Effects نفسه غير متاح في البيئة، ولم يتم الادعاء بتشغيل الاختبار داخله.

الطبقات مناطق تعديل من نسخ متزامنة لنفس بكسلات الفيديو فوق الأصل الكامل. لا توجد إعادة رسم أو فصل للبنت. إخفاء نسخة البيت يُظهر البيت الموجود في الأصل تحتها؛ ليست هذه طبقات الأنيميشن الأصلية أو عزلًا لحذف العناصر. داخل المشروع مقارنة Difference لفحص النتيجة عند التشغيل. إعادة تصدير MP4 بضغط فقدي قد تغيّر البكسلات حتى لو المشهد متطابق بصريًا؛ الفيديو المرفق نفسه لم يتغير.

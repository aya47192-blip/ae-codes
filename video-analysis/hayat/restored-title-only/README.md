## ما تغير

إزالة الإطار الأسود وتعليق تيك توك، ومسح شعارات وأسماء بداية الفيلم مع إبقاء كلمة«حياة» وتصميمها وحركتها الأصلية. يُرمّم فقط الجزء المحجوب خلف الكتابة من فريمات خلفية الأصل/ترميم محلي. نهاية الملف عند نهاية مشهد الحكاية128.7ثانية، قبل كارت التترات. لا توجد بيانات النهاية.

تحسيندقة استدلالي FSRCNN على كل فريم من المصدر، ثم إخراج1152×632، مع تصحيح لون خفيف وحدّة طفيفة. لم تُولّد حركة جديدة، ولم يتم تغيير سرعة الفيلم أو استيفاء فريمات بينية. كل فريم إخراجi يقابل فريم المصدرi، وعددها3861 عند30fps. صوت المصدر في الجزء المحتفَظ به نُسخ دون إعادة ترميز وتطابقت بصمته الرقمية بعد القص.

**حدود الجودة:** المصدر الفعلي576×316 داخل ملف رأسي مضغوط. المعالجة قد تحسن بعض الحواف لكنها لا تستعيد تفاصيل رسم أصليةHD غير موجودة، وقد تبقى بعض نعومة المصدر وآثار ضغطه. هذه ليست إعادة رسم للفيلم من الصفر، لأن ذلك قد يغير الرسوم والحركة. افحصي مقطع الحركة والمقارنة قبل الحكم على النتيجة.

## After Effects

الحزمة تضم الفيديو وسكربت Build_Restored_Hayat_AE.jsx. فكي ZIP ثم File > Scripts > Run Script File داخل AE. ينشئ ويحفظAEP على جهازك مع الميديا وطبقة تصحيح محايدة قابلة للتعديل. **لا يوجدAEP محفوظ مسبقًا** لأنAfter Effects غير متاح هنا. إزالة الكتابة وتحسين الفريمات مطبوعان داخلMP4، وليس هذا مشروع أنيميشن بالشخصيات المفصولة. الصياغة البرمجية فُحصت، لكن تشغيل السكربت فيAE نفسه لم يُختبر هنا.

[نموذجFSRCNN المستخدم](https://github.com/Saafke/FSRCNN_Tensorflow)

ملفاتPSD المصححة موجودة بجوار هذا المجلد فيpsd-v2-corrected، على فرع التسليم نفسه. لم يتم تعديلmain.

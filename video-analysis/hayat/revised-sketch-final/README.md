# حياة — Storyboard مبدئي ونهائي بدون كروت كتابة

- [كل الملفات والصور ZIP](Hayat_Storyboard_Sketch_Final_NoTitles.zip?raw=true)
- [Storyboard Sketch — PDF](Hayat_Storyboard_SKETCH.pdf)
- [Storyboard Final — PDF](Hayat_Storyboard_FINAL.pdf)

36 لوحة في 6 صفحات لكل نسخة. استُبعد العنوان والتترات والاعتمادات، وقُصّ تعليق تيك توك والإطار الأسود. الصفحات بلا عناوين أو توقيتات مكتوبة فوق الرسم؛ توقيتات المصدر موجودة في CSV داخل ZIP. القراءة بالصف من اليسار إلى اليمين.

Sketch: إعادة رسم توضيحية بالذكاء الاصطناعي بأسلوب خطوط قلم سوداء على أبيض، وليست storyboard الإنتاج الأصلية. قد تختلف تفاصيل دقيقة عن المصدر.
Final: نفس اللقطات من الفيلم، بما فيها اللقطات الرمادية في بداية العمل. الكتاب ضمن الحكاية لا يحتوي نصًا مقروءًا.

ZIP يضم PDF لكل نسخة، و12 صورة للصفحات، و72 صورة للوحات منفصلة (36 لكل تقنية)، وتوقيتات المصدر. لا تتضمن هذه المراجعة معالجة الفيديو الثاني؛ ينتظر اعتماد المستخدمة.

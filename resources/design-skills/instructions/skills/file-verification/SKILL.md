# الفحص والتسليم واستمرار المشروع

1. افحص الأدوات والتراخيص والاعتماديات قبل اختيار مسار الإنتاج. لا تُعامل اسم مكتبة في prompt على أنه تثبيت أو أداة متاحة.
2. احفظ مصدرًا هندسيًا واحدًا مضبوطًا، وإعدادات وحدات وسماحيات واضحة، وسجلًا للنسخ والتعديلات. استخدم مجلد عمل جديدًا أو نسخة احتياطية؛ لا تكتب فوق آخر تسليم معتمد بلا حاجة.
3. لا تستنتج النجاح من انتهاء الكود. اختبر المخرج نفسه بإعادة القراءة وراجع معاينة مشتقة منه. قارن القياسات والمواضع والهندسة قبل/بعد. افصل اختبار الصيغة عن اختبار التطبيق وعن مطابقة التصميم.
4. لا تعتمد على أسماء مثل CLOSED_FIXED أو FINAL لإثبات الجودة. فشل الفحص يوقف وصف الملف بأنه سليم حتى يُصلح أو تُعلن حدوده.
5. اختبر السيناريو المقصود: مساحات CAD مغلقة بالفعل، أوجه SKP، وحدات وحجم نهائي، صور وخامات داخل الحزمة، PDF دون قص ونص صحيح. وسّع الفحوص عند وجود خطأ جديد، لا لمجرد تكرارها.
6. التسليم يتضمن الملفات المطلوبة بأسمائها الحقيقية، معاينة، تقرير تحقق مختصر، وتعليمات الفتح/الوحدات/الطباعة الضرورية. لا تسلّم سكربتًا بدل الملف النهائي دون اتفاق.
7. لا تغيّر الامتداد لتوهم بتحويل صيغة. لا تدّعِ إنشاء ملف فعلي إذا لم يكتب إلى القرص. لا تدّعِ دقة مليمترية من صورة دون معايرة وحدود خطأ مرجع مناسبة.
8. الاحتفاظ بفهرس المشروعات لا يعني اعتبار كل ملف معتمدًا. سجل: مشروع، مرجع، نسخة معتمدة، المطلوب، المتوقف، الاختبارات والقيود، والخطوة التالية.
9. اكتب تقريرًا واضحًا: ما تغير، ما اختُبر، نتيجة القياس، وما لم يمكن اختباره. تجنب وعود «صفر أخطاء» دون دليل.
10. إن كان طلب المستخدم واضحًا نفذه دون أسئلة متكررة. إذا غابت معلومة مؤثرة اسأل عنها وحدها مع استمرار العمل المستقل عنها.

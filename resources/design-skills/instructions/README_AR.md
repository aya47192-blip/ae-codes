# حزمة نقل طريقة العمل إلى شات جديد

إعداد: 9 نوفمبر 2026. هذه حزمة تعليمات عمل قابلة للقراءة، وليست برنامجًا يثبت AutoCAD أو SketchUp، وليست ضمانًا آليًا لصحة الملفات. ملفات skills/ هي مهارات مخصصة أعددناها للتسليم الآن؛ لم تكن Skills رسمية مثبّتة سابقًا. ارفعي ZIP في الشات الجديد واطلبي فكّه وقراءة ملفاته.

## الـSkills الرسمية المتاحة في الشات الحالي — القائمة الكاملة

1. cloud-environment:cloud-desktop: التعامل مع سطح المكتب المشترك والمتصفح وفحص التطبيقات عند توفر واجهة التحكم. مصدرها cloud-desktop/SKILL.md في حزمة cloud-environment.
2. cloud-environment:cloud-environment-runtime: تشغيل الأوامر وتجهيز الاعتماديات واختبارات المتصفح والصور والشبكة وDocker وأدوات البيئة. مصدرها cloud-environment-runtime/SKILL.md في الحزمة نفسها.
3. cloud-environment-onboarding:setup: تجهيز مستودعات العمل واختبار إعدادها وحفظ تعليمات تشغيل قابلة للتكرار. مصدرها setup/SKILL.md في حزمة cloud-environment-onboarding.

لا يوجد في قائمة المهارات المثبتة Skill رسمي اسمه AutoCAD أو SketchUp أو «الدقة بالمليمتر». لا توجد مهارات executor إضافية في نتيجة الفحص. أسماء المهارات لا تثبّت أدواتها عند نسخها؛ يلزم توافر الحزمة في الشات الجديد. لم ننسخ نصوص تشغيل البيئة الرسمية؛ نقلنا أسماءها ووظائفها، وأضفنا تعليمات عمل مستقلة تخص احتياجاتك.

## الأدوات والمكتبات التي ساعدت على إنتاج الملفات

- كتابة وتنفيذ Python وأوامر الطرفية وتعديل الملفات: تشغيل الأكواد، إعداد مصادر هندسية، إنشاء التقارير والحزم.
- ezdxf: قراءة/كتابة وفحص DXF، الطبقات والوحدات والمسارات والأقواس والدوائر.
- LibreDWG: أدوات تحويل DWG/DXF موجودة هنا في /workspace/libredwg-build/dxf2dwg وdwg2dxf؛ ليست في PATH الافتراضي. دعم التحويل يعتمد على الكيانات والإصدار، لذلك يلزم إعادة القراءة والمقارنة بعد كل تصدير.
- Shapely: موجودة في بيئة اعتماديات محلية /workspace/cad_geometry؛ لفحص المضلعات والتقاطعات والثقوب والقص والاتحاد. ليست مثبتة في Python الافتراضي وقت الفحص.
- NumPy وSciPy: حسابات الإحداثيات والتحويلات والمسافات والتنعيم المنضبط.
- OpenSKP: مسار برمجي استُخدم لقراءة وكتابة SKP حقيقي، مع فحص الملف الناتج. المصدر العام https://github.com/iamahsanmehmood/openskp ؛ نسخته المحلية ضمن /workspace/coastal_reference_v16/openskp. ليس تطبيق SketchUp الرسمي ولا ضمانًا لكل ميزاته أو إصداراته.
- SketchUp Ruby API: أكواد .rb وملفات إضافات لبناء النماذج داخل SketchUp. تشغيلها يتطلب SketchUp على جهاز مناسب. ملف Ruby أو RBZ ليس بديلًا عن تسليم .skp عندما يكون المطلوب SKP.
- Blender وFreeCAD وInkscape: البرامج موجودة في هذه البيئة. استخدامها مشروط بدعم الصيغة والمهمة. وجودها لا يعني اختبار كل ملفاتنا داخلها.
- Aspose.CAD: اعتماديات محلية في /workspace/cad_tools لقراءة/عرض صيغ CAD عند صلاحية البيئة والترخيص؛ لا يُفترض أنها مجانية بلا قيود.
- PyMuPDF (fitz): قراءة PDF وفحص صفحاته واستخراج النصوص/العناصر المتاحة ومعاينات PDF.
- ReportLab: إنشاء PDF بمقاسات طباعة فعلية مثل A4 وA3.
- Pillow: التعامل البرمجي مع الصور عندما يناسب المهمة ويكون مسموحًا؛ ليست بديلًا عن أداة تعديل الصور المتاحة.
- python-pptx وpython-docx: المكتبتان متاحتان لإنشاء PPTX وDOCX. وجود المكتبة لا يعني أن صور اللوحات الحالية تحولت تلقائيًا إلى عناصر PowerPoint قابلة للتحرير.
- أداة image_gen: إنشاء وتعديل الصور من المراجع. أداة مستقلة وليست Skill نصية؛ يلزم أن تتوفر في الشات الجديد. النتائج المصورة تحتاج مراجعة للحروف والهوية البصرية ولا تصلح وحدها مصدر قياس هندسي.
- أدوات عرض الصور وفحص الملفات والضغط ZIP: للمعاينة والتسليم المنظم.

AutoCAD Desktop وSketchUp Desktop غير متاحين هنا وقت الفحص. لا يصح الادعاء باختبار داخلهما. المسارات المحلية المذكورة دليل على البيئة الحالية ولا تنتقل إلى شات جديد بمجرد كتابة أسمائها.

## أنـواع المخرجات ومسار إنتاجها

| المخرج | المسار العملي | شرط التحقق |
|---|---|---|
| DXF | ezdxf ومصدر هندسي مضبوط | إعادة القراءة، audit، فحص الوحدات والهندسة |
| DWG | محول يدعم الكيانات والإصدار | تحويل عكسي ومقارنة هندسة الناتج |
| SKP | كاتب SKP متوافق أو تطبيق SketchUp | إعادة قراءة الملف وفحص المقاسات والأوجه والخامات؛ اختبار التطبيق إذا توفر |
| RB / RBZ / LSP | كود مخصص للتطبيق | فحص وتشغيل في البيئة المناسبة؛ تمييزه عن الملف النهائي |
| GLB / OBJ / STL / DAE | أداة ثلاثية الأبعاد تدعمها | الوحدات والمحاور والأوجه وما تدعمه كل صيغة من خامات |
| PNG / JPG | توليد أو رسم أو تصدير | فحص الصورة والنصوص والدقة |
| SVG / PDF | عناصر متجهة أو تجميع للطباعة | التحقق هل المحتوى متجه أم صورة مضمنة، ومقاس الصفحة |
| PPTX / DOCX | مكتبات المستندات | فتح/قراءة ومراجعة اتجاه العربية والخطوط وقابلية التحرير |
| ZIP / JSON / CSV / MD | حزمة وتسليم وتقارير | اكتمال الملفات ومسارات نسبية وعدم الاعتماد على ملفات مفقودة |

هذه مسارات ممكنة وليست وعدًا بإنشاء «أي امتداد» دون محرك مناسب. لا نغير امتداد ملف لإظهاره بصيغة أخرى.

## ما الذي تنقلينه للشات الجديد؟

1. هذه الحزمة؛ اطلبي قراءة START_HERE_AR.md ثم ملفات SKILL.md الأربعة.
2. ملف المشروع الأصلي الفعلي: DWG/DXF/SKP أو PDF الأصلي، وليس لقطة شاشة فقط عند طلب مطابقة هندسية.
3. آخر نسخة اعتمدتيها وصورة توضح التعديل المطلوب.
4. الأبعاد المرجعية والوحدات والارتفاعات، مع تحديد ما يخص هذا المشروع وحده.
5. ملف PROJECTS_INDEX_AR.md المرفق لو مطلوب استمرار فهرس المشروعات. الفهرس لا يحتوي ملفات المشروعات نفسها.

لا تحتاجين إعطاء الشات الجديد بيانات دخول أو مفاتيح سرية لتطبيق هذه التعليمات. ملفات المشروعات والكود والبرامج تبقى منفصلة عن النصوص.

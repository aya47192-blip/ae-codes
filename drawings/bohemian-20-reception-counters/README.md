# ٢٠ كاونتر ريسبشن للّوبي البوهيمي B1

[تحميل الإكستنشن](Ayaa_Bohemian_20_Lobby_Reception_Counters_v1_0.rbz)

هذه مكتبة بدائل ريسبشن، متوافقة مع خامات آخر لوبي بوهيمي: خشب طبيعي وخوص وجص أوف وايت وحجر دافئ وزيتوني ونحاس معتق. كل كاونتر مختلف في تكوينه أو شكل واجهته وتفاصيله المجسمة، وليس مجرد تغيير ألوان. كل قطعة Component كامل مستقل بداخلها أجزاء قابلة للتعديل.

## الحصول على ملف SketchUp SKP

1. ثبّتي RBZ بدون فك الضغط من **Extensions > Extension Manager > Install Extension**. أعيدي تشغيل SketchUp إذا لم تظهر القائمة.
2. افتحي **File > New**، ثم **Extensions > Ayaa Boho Counters 1.0 > Build ALL 20 and save SKP**.
3. تُبنى القطع في شبكة متباعدة، ثم تظهر نافذة حفظ ملف **Ayaa_Bohemian_20_Reception_Counters.skp**. اختاري مكانًا واسمًا جديدًا. بذلك يحفظ SketchUp ملف SKP بنفسه.
4. **Browse 20 reception counters** يعرض كتالوج الصور والأبعاد ويتيح إدراج قطعة واحدة داخل موديل اللوبي. **Place ONE reception counter** يقوم بالإدراج مباشرة من القائمة. الاختيار لا يحذف الريسبشن القديم تلقائيًا.

لا يتوفر هنا SketchUp Desktop لتوليد واختبار ملف SKP مباشر؛ التسليم RBZ ينشئ الهندسة داخل SketchUp ثم يستخدم حفظه الأصلي. فُحصت الهندسة والأرشيف وصياغة Ruby، لكن البناء والحفظ داخل التطبيق لم يُختبرا هنا.

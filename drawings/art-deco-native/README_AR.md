# تحويل الواجهة الأصلية إلى آرت ديكو — ملف CAD هندسي

المصدر: `واجهه تعديل 1.dwg`. هذه النسخة مبنية على إحداثيات الملف المرفوع، وليست تتبّعًا للصورة المولّدة السابقة.

- [تحميل DXF](art_deco_facade.dxf)

- [مقارنة قبل وبعد PDF](before_after.pdf)

- [تحميل الحزمة كاملة](art_deco_package.zip)

التغيير المعماري: إطارات مستطيلة متدرجة بدل الحليات الكلاسيكية، شرائط رأسية ذات تخديدات مستقيمة، ألواح هندسية معيّنة بين الشبابيك، وتاج أشعة متدرج داخل حدود السقف الأصلية. أُزيلت زخارف أسنان الكورنيش. لم تُضف فتحات أو أدوار، وحُفظت إحداثيات حدود زجاج ٥٣ شباكًا كبيرًا و٣٣ شباكًا صغيرًا، بما فيها الاختلافات الأصلية في مواقعها ومناسيبها. أُعيدت صياغة الحليات المحيطة بها ضمن التحويل المطلوب.

كل طبقات الرسم بلون AutoCAD التكيفي ACI 7: أسود على الورق الأبيض، وأبيض على خلفية Model الداكنة. السمك الموحّد 0.25 مم. ملف PDF يستخدم الأسود RGB(0,0,0) بلا تهشير رمادي أو صور مدمجة. حدود البروفيلات المغلقة مكتملة، بينما التقسيمات الداخلية والخطوط المشتركة ممثلة مرة واحدة في شبكة متصلة؛ لا يتم إغلاق الخطوط الداخلية بإضافة أضلاع مصطنعة.

| الطبقة | المحتوى |
|---|---|
| 01_STRUCTURE | كتلة المبنى وحدوده والكمرات والأعمدة |
| 02_OPENINGS | الزجاج وتقسيماته |
| 03_STEPPED_FRAMES | إطارات آرت ديكو المتدرجة |
| 04_VERTICAL_RIBS | التخديدات والشرائط الرأسية |
| 05_GEOMETRIC_RELIEF | الزخارف الهندسية والتاج |
| 06_ORIGINAL_SIDE_DETAILS | تفاصيل الإسقاط الجانبي الأصلية |

التحقق: ٥١٣١ عنصرًا في DXF وDWG؛ إعادة تحويل DWG وقراءته أعادت العدد نفسه مع فارق إحداثيات صفري، ومن دون تحذيرات تحويل أو أخطاء أو إصلاحات في فحص ezdxf. جرى فحص اكتمال ٤٥٨ محيطًا، وعدم وجود مقاطع بطول صفر أو تراكب خطي مؤثر. الأقواس الجانبية الأصلية محفوظة كأقواس هندسية. تفاصيل الفحص في `validation.json`، وجدول زجاج الفتحات في `window_schedule.json`.

ملاحظة الوحدات: المصدر مسجّل في INSUNITS كـ inches، بينما أبعاده الرقمية تتضمن أدوارًا بقيمة 3.0؛ احتُفظ بالإحداثيات ورمز الوحدة دون تحجيم أو افتراض مقاس حقيقي جديد. DWG بصيغة AutoCAD 2000 المتوافقة مع الإصدارات الأحدث. لم يُفتح الملف داخل برنامج Autodesk AutoCAD نفسه؛ فحص البنية والهندسة لا يمثل اعتمادًا تنفيذيًا للمشروع.

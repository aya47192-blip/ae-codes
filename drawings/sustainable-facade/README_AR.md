# الواجهة المستدامة — تتبّع الصورة الأصلية، نسخة للمراجعة

[تحميل الكاد فقط داخل ZIP](facade_cad.zip) — نسخة توافق AutoCAD 2000 بنفس الإحداثيات، ولون 7 الذي يظهر فوق الخلفية السوداء أو البيضاء. افتحي صفحة الملف ثم اختاري Download raw file، وفكّي الضغط قبل فتح DXF.

المصدر هو [IMG_3106.PNG](../../IMG_3106.PNG) الذي رفعته صاحبة المشروع. هذا التصدير يستخرج مسارات الصورة نفسها ولا يعيد تصميم واجهة بديلة.

**هذه النسخة ليست مطابقة مضمونة بنسبة 100%، ولا تحقق شرط إغلاق كل المسارات.** الاستخراج من الصورة قد يقطع الخطوط الخفيفة أو يدمج خطوطًا متقاربة ويترك انحرافات صغيرة في المسارات. لم تُضف زخارف أو نباتات مُصممة يدويًا بدل المرجع. راجعي المعاينة والمقارنة قبل اعتماد الرسم.

## النتيجة وحدودها

- جميع كيانات الرسم سوداء بسمك طباعة موحّد **0.13 مم**، وبعرض هندسي صفر. لا يوجد إطار أو نص أو أبعاد مضافة فوق الواجهة.
- يحتوي DXF على **17,851** مسارًا و**40,832** مقطعًا، منها **1,718** مسارًا مغلقًا مستقلًا. مسارات أخرى تلتقي لتكوّن شبكة من الحدود، وأخرى مفتوحة.
- فحص المقاطع المتطابقة: **0**. فحص سلامة DXF: **0** أخطاء و**0** إصلاحات آلية.
- توجد **9,947** نهاية بدرجة اتصال واحدة. بعضها مقصود، مثل انعكاس الزجاج وأوراق النبات، وبعضها ناتج عن انقطاع التفاصيل في الاستخراج؛ لم يتم تصنيف كل نهاية يدويًا. لذلك لا يصح اعتبار الملف شبكة مغلقة بالكامل أو صالحة لتوليد HATCH آلي لكل واجهة دون مراجعة.
- تم وصل **314** فجوة صغيرة فقط حين اتفق اتجاه الطرفين ووجد خط داكن يدعم الاتصال في الصورة، وليس بمجرد قرب الخطين.
- قياس المسافة بين المسارات وشبكة البكسلات المستخرجة يفحص خطوة التحويل، **ولا يثبت أن جميع خطوط الصورة الأصلية استُخرجت أو أنها مطابقة 100%**.
- عرض خط الأرض مفترض **20,000 مم**، وارتفاع أعلى ألواح الشمس يقارب **8.2 م**. هذه تقديرات وليست مقاسات من مخطط أصلي. الـPDF مطبوع بمقياس اسمي 1:50 على A3، ويجب تعطيل Fit to page عند الطباعة لعدم تغيير المقياس.
- DXF هو الملف المتاح لفتح الرسم في AutoCAD. لم يتم إنشاء DWG أصلي؛ يمكن حفظه DWG من AutoCAD بعد فتح DXF.
- ملف PDF متجهي، لا يحتوي صورة مضمّنة. بياض خلفية AutoCAD إعداد في البرنامج نفسه: OPTIONS → Display → Colors → 2D model space → Uniform background → White. اللون الأسود الصريح قد لا يُرى فوق الخلفية السوداء.

## تشغيل AutoLISP

1. افتحي رسمًا بوحدة المليمتر. شغّلي APPLOAD واختاري sustainable_facade.lsp.
2. اكتبي SUSTAIN، ثم اختاري نقطة الإدراج. عرض خط الأرض الافتراضي 20000 مم ويمكن تغييره.
3. الرسم يُدرج كبلوك واحد؛ استخدمي EXPLODE للوصول إلى مساراته، وZOOM → Extents لإظهاره.
4. إعادة تشغيل SUSTAIN تضيف نسخة جديدة؛ لا تشغليه فوق النسخة السابقة إذا لم تكوني تريدين تكرار الرسم.

الكود يحتوي كل الإحداثيات ولا يحمّل ملفات خارجية ولا يشغّل أوامر نظام. جرى تحليل الكود وتنفيذ مولّد المسارات في **محاكاة** ومقارنة بياناته بكل مسارات DXF. **لم يُشغّل داخل AutoCAD فعليًا.**

## الطبقات

| الطبقة في DXF | المحتوى التقريبي بحسب موضعه في المرجع |
| --- | --- |
| ARCHITECTURE | حدود الواجهة والإطارات والتفاصيل المعمارية |
| SOLAR | مسارات منطقة الألواح الشمسية |
| PLANTING | مسارات مناطق الزرع |
| MASONRY_AND_ARCH | مسارات مناطق الحجر وما يقع داخلها من عمارة |

التصنيف بحسب مناطق الصورة، وليس نموذج BIM للعناصر. أسماء طبقات AutoLISP تبدأ بـ SF_. السمك واللون موحّدان في جميع الطبقات.

## إعادة توليد الملفات

البرامج في tools ومكتباتها المثبتة الإصدارات في requirements.txt. من نفس المجلد بعد تثبيت المكتبات:

```bash
python tools/probe.py
python tools/ridges.py
python tools/build.py
python tools/export_lisp.py
python tools/check.py
```

تُحفظ النتائج في output داخل tools افتراضيًا. يمكن تحديد المصدر بإعداد FACADE_SOURCE وتحديد مجلد الإخراج بإعداد FACADE_OUTPUT. يلزم وجود مكتبة Cairo للنظام لتصدير PDF. تتبّع التفاصيل بدأ بعينة مكبّرة 3 مرات، وتخفيف المسارات بتسامح 0.23 بكسل، وضبط الخطوط القريبة من المحاور المقاسة في حدود 0.65 بكسل؛ هذه حدود حاسوبية وليست دقة مساحية.

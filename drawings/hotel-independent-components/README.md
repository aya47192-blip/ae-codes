# اللوبي — فصل كل قطعة كاملة كمكوّن مستقل

[النيو مودرن](new_modern_components.zip) · [البوهيمي الأخير V2](bohemian_latest_components.zip)

كل حزمة تحتوي DAE منفصلًا لكل عنصر، والخامات، وملف IMPORT_COMPONENTS.rb. المساعد يستورد العناصر واحدًا تلو الآخر ويغلف كل عنصر كامل كـComponent مستقل في المستوى الرئيسي، ثم يطبق تحويله الأصلي ويحفظ SKP. هكذا لا يعتمد الفصل على احتفاظ مستورد COLLADA بالهرمية الداخلية لملف كبير واحد. لا توجد مجموعة رئيسية تحبس كل اللوبي.

كل نسخة بها 33 قطعة أثاث مستقلة كاملة؛ الإضاءة والديكور ومناطق الأرضية مستقلة أيضًا. جسم المبنى الثابت مكوّن معماري منفصل. النيو مودرن 160 مكوّنًا إجمالًا والبوهيمي239. كل قطعة لها تعريف مستقل، لذلك تغيير واحدة لا يغيّر بقية الكراسي تلقائيًا.

## التشغيل

1. فكّي ZIP كاملًا في مجلد قابل للكتابة.
2. افتحي SketchUp Desktop بملف جديد وفاضي، وامسحي الشخص الافتراضي إن وجد.
3. افتحي Ruby Console، ثم اكتبي:

```ruby
load UI.openpanel('Choose IMPORT_COMPONENTS.rb', nil, '*.rb')
```

4. اختاري IMPORT_COMPONENTS.rb من المجلد المفكوك وانتظري اكتمال الاستيراد والحفظ. لا تستوردي ملفات parts يدويًا.
5. حددي الكرسي أو الترابيزة بنقرة واحدة. استخدمي Move أوScale مباشرة، ولا تعملي Explode. لتعديل ما داخل القطعة استخدمي الدبل كليك.

## المراجعة وحدودها

تطابقت محتويات كل شبكات الموديل وتحويلاتها مع المصدر، دون حذف أو تكرار. أُعيدت قراءة جميع الملفات بمكتبة pycollada مستقلة:1987 شبكة للمودرن و2795 للبوهيمي، بأقصى فرق في حدود الإحداثيات أقل من0.016ملم، وجميع خرائط الخامات موجودة. التصميم نفسه كما في النسخ السابقة؛ التغيير في طريقة الفصل والاستيراد فقط.

الحزمة ليست SKP أصليًا من هنا؛ المساعد يكتبه داخل SketchUp Desktop. لم يتوفر البرنامج لاختبار تشغيل المساعد فعليًا هنا. يجري المساعد تحققًا داخل SketchUp من أن جميع العناصر الرئيسية Components مستقلة، دون خطوط أو أوجه سائبة في المستوى الرئيسي، ثم يكتب sketchup_import_report.json.

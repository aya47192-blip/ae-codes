# الساحلي — نفس التصميم المعتمد، بناء أصلي داخل SketchUp

[تحميل الإضافة RBZ](Ayaa_Coastal_Same_Design_v1_6_1.rbz)

## التشغيل

1. نزّلي ملف **RBZ كما هو، بدون فك الضغط**.
2. في SketchUp: **Extensions > Extension Manager > Install Extension**، واختاري الملف.
3. اقفلي جميع نوافذ SketchUp وافتحيه مرة ثانية، ثم **File > New**.
4. من **Extensions > Ayaa Coastal 1.6.1** اختاري **Build COASTAL - approved design + mixed plants**.
5. بعد اكتمال البناء اختاري مكان حفظ SKP. كل قطعة كاملة Component مستقل.

يبدأ العرض ببلان علوي بإسقاط متوازٍ. للعرض المجسّم اختاري **View COASTAL 3D - parallel** من نفس القائمة. ويمكن الرجوع للبلان باختيار **View TRUE PLAN - parallel**. توجد أيضًا Scenes للبلان و3D.

## ما تغيّر

التصميم الساحلي الذي وافقتِ عليه محفوظ: الأعمدة الأيونية البيضاء، الجداريات، الفرش، الريسبشن، المدخل والسنتر البيضاوي بدرجتين. هذه الحزمة تستخدم مصدر الهندسة نفسه، وتحافظ على كل جزء داخل سياق هندسته وتحويلاته الأصلية، ثم تنشئ الموديل بواجهات SketchUp الأصلية بدل كاتب SKP المباشر. راجعت تطابق كل أجسام المصدر القديم في إحداثياته وهندسته وخاماته وظهوره؛ لم يُحذف أو يتغيّر أي جسم سابق.

الإضافات: 7 أصاري داخلية مستقلة، و5 إكسسوارات حائط صغيرة، مع إبقاء الموجود. الحوضان الخارجيان فيهما الزرع السابق مع غطاء أرضي كثيف، ولافندر، وأجاف، وأعشاب زينة، وأشجار زيتون في العمق بعيدًا عن الشبابيك. الغطاء الأرضي الجديد وحده يغطي أكثر من 99% من مساحة كل حوض، إضافة إلى بقية النباتات. راجعت الأصاري ضد الفرش والأعمدة والفتحات ومسارات الوصول التخطيطية.

إصلاحات UI.refresh وفحص حدود القطع المدورة من الإصدار الذي عمل عندك محفوظة. لا يستخدم هذا الإصدار كاتب SKP المباشر أو استيراد DAE. [نتائج الفحص](verification.json).

تم فحص حزمة الإضافة وصياغة Ruby والخامات وبيانات الهندسة، ومقارنتها بالمصدر، لكن لم يتوفر SketchUp Desktop هنا لاختبار تشغيل البناء داخل التطبيق نفسه.

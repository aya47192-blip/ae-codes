# جميع الكونسبتات — نسخة Outline

هذه ملفات PDF بمظهر outline مستوحى من طباعة CAD، وليست ملفات DWG أو DXF قابلة للتحرير. تحتوي الصفحات صور الخطوط الناتجة عن تحويل بصري؛ لم تُتحقق المطابقة الرقمية لكل خط أو إغلاق كل حد هندسي. سمك الخط متقارب بصريًا، وليس وزن CAD رقميًا موحدًا. للاستخدام التنفيذي يلزم الرجوع لقاعدة CAD وضبط الخطوط والأبعاد.

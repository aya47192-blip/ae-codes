# الواجهات الثلاثة — كاد بشبابيك معدلة

## الملفات

- `00_Three_Facades.dwg` و`00_Three_Facades.dxf`: الواجهات الثلاثة في ملف واحد، بنفس إحداثيات المصدر.
- `01_Art_Deco`: الواجهة الأولى، تقسيمات هندسية وإطارات وحشوات علوية جديدة.
- `02_Art_Nouveau`: الواجهة الثانية، تقسيمات زجاج وخطوط نباتية جديدة.
- `03_Victorian`: الواجهة الثالثة، ضلف غير متساوية وتفاصيل زجاجية ورؤوس مزخرفة.

كل واجهة لها DWG وDXF مستقلان. صيغة DWG هي AutoCAD 2000 المتوافقة مع الإصدارات الأحدث.

## الشبابيك والبلكونات

استبدل تصميم الإطارات والضلف وتقسيمات الزجاج. في بعض الفتحات المقوسة، تغطى الرأس القديمة بحشوة واجهة، ويظهر الزجاج مستطيلا داخل الفتحة القائمة. لا يقترح قص أو توسيع الفتحة الإنشائية. تبقى الفتحات الخلفية للبلكونات خلف القفلات الزجاجية المقترحة داخل عرض البلاطات الحالية.

## تنظيم الرسم

- `01_EXISTING_RETAINED`: الخطوط القائمة الظاهرة بعد تغطيتها بمعالجة الواجهة.
- `02_NEW_FACADE`: الكسوة والحليات الجديدة.
- `03_NEW_WINDOWS`: الشبابيك الجديدة، كل شباك بلوك مستقل.
- `04_GLAZED_ENCLOSURES`: قفلات البلكونات، كل قفلة بلوك مستقل.
- `90_ORIGINAL_REFERENCE_OFF`: مرجع الشكل الأصلي، مغلق افتراضيا للمقارنة فقط. ليس جزءا ظاهرا من المقترح.

الرسم ثنائي الأبعاد وقابل للتعديل، بخطوط ACI 7 ووزن 0.25 مم. الدوائر والأقواس والمنحنيات عناصر كاد أصلية؛ المنحنيات النباتية SPLINE، والحدود المستقيمة المغلقة LWPOLYLINE. قوائم الشبابيك وخطوط الطوب خطوط مفتوحة حيث يلزم في الرسم المعماري، وليست كل ضلفة مساحة مصمتة.

حفظت الإحداثيات الرقمية وعلامة وحدات المصدر كما هي؛ لم يفترض مقياس جديد بالمتر أو المليمتر. هذه رسومات تصميم واجهات، وليست مستندات تعديل إنشائي أو تفاصيل تركيب تنفيذية.

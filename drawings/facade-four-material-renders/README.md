# Four CAD-derived facade material previews

Front material studies derived from uploaded native CAD linework. Embedded IMAGE entities were ignored. Original source files are unchanged. Proposed uses and material families are provisional, not construction specifications. Relief depths are illustrative; no side elevations were supplied.

- Four_Facades_Material_Review_AR.pdf: Arabic review, renders, native vector checks and limitations.
- 01–04 .png/.jpg: individual front studies.
- Four_Facades_Overview.jpg: comparison.
- Four_Facades_Images.zip: all images and PDF.

# إصلاح تشغيل Ayaa Lobby 1.4.1

[تحميل الحزمة الكاملة RBZ](../hotel-native-builder/Ayaa_Lobby_Components_v1_4_1.rbz)

## التركيب

1. نزّلي ملف **Ayaa_Lobby_Components_v1_4_1.rbz** بدون فك الضغط.
2. داخل SketchUp: **Extensions > Extension Manager > Install Extension**، واختاري الملف.
3. اقفلي **كل نوافذ SketchUp** وافتحيه مرة أخرى، ليُحمّل الإصلاح قبل بدء البناء.
4. افتحي ملفًا جديدًا، ثم **Extensions > Ayaa Lobby 1.4.1** واختاري **Build BOHEMIAN V5** أو **Build GREEK COASTAL V4**.
5. احفظي ملف SKP بعد اكتمال البناء. كل قطعة فرش Component مستقل.

## سبب اختفاء الموديل

الإصدارات القديمة قد تستدعي `UI.refresh` بعد إنشاء الأجزاء الأولى. SketchUp لا يوفر هذه الدالة؛ فتظهر رسالة NoMethodError وينفّذ معالج الخطأ `abort_operation`، فيختفي ما بُني داخل العملية. الحزمة الجديدة تضيف دالة توافق للاستدعاء المفقود إذا لم تكن موجودة أصلًا، وتوجهه إلى تحديث العرض المتاح في active_view. هذا يشمل الاستدعاء القادم من كود نسخة قديمة ما زالت محمّلة. أخطاء إعادة الرسم الاختيارية لا تُسقط عملية إنشاء الهندسة.

لا يستبدل الإصلاح دالة UI.refresh موجودة مسبقًا. له مسار تحميل وmodule وقائمة إصدار منفصلة. البناء الجديد نفسه يستعمل دالة التحديث المحمية، ويكتب تفاصيل أي خطأ هندسي لاحق واسم القطعة في `Ayaa_Lobby_141_error.log` داخل مجلد Windows المؤقت، ويعرض المسار في الرسالة.

## التصميم والفحص

كل بيانات الموديلات والخامات والصور في الحزمة مطابقة بايتًا لنسخة 1.4.0: البوهيمي V5 والساحلي V4 وخيارا المودرن السابقان. لم تُغيّر التوزيعات أو الحوائط أو الريسبشن في إصلاح التشغيل. [معاينة التصميمات](../hotel-distinct-update-1-4/DISTINCT_LOBBY_PREVIEW.pdf).

أُعيد إنتاج غياب UI.refresh باختبار Ruby فعلي، ثم نجح استدعاؤها بعد تحميل الإصلاح. شملت الاختبارات عدم تغيير دالة موجودة، وتكرار التثبيت، وغياب الموديل أو العرض، وبديل View.refresh، وعزل استثناء إعادة الرسم عن عملية البناء. بيئة الاختبار تحاكي عناصر واجهة SketchUp؛ لا تنفذ SketchUp نفسه أو إنشاء الهندسة داخله. تمت مراجعة صياغة Ruby وسلامة CRC وكل مراجع أجزاء الحزمة وخاماتها. [نتائج الفحص](verification.json) · [اختبار Ruby](test_refresh_compat.rb).

الإضافة تنشئ ملف SKP داخل SketchUp؛ ليست ملف SKP جاهزًا للتنزيل. تشغيلها الفعلي داخل SketchUp Desktop ما زال غير متاح هنا.

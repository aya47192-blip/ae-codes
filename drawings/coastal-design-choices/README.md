# الساحلي — PDF الاختيار قبل تنفيذ SketchUp

[تحميل PDF واحد: ١٠ توزيعات + الأرضيات + الحوائط + الدخلة](COASTAL_10_LAYOUTS_AND_WALLS.pdf)

الملف ١٧ صفحة: عشرة توزيعات مختلفة L1–L10، وثلاث أرضيات F1–F3، وثلاث عائلات لتصميم الحوائط W1–W3، وثلاثة تصورات للدخلة E1–E3، وصفحة للزراعة والأباليك ومراجعة الحوائط. اختاري الأكواد التي تناسبك قبل أي تنفيذ جديد في SketchUp.

المخططات مبنية على مقطع الحوائط الأصلية و22 عمودًا وحدود أحواض الزراعة الأصلية، مع الفتحات والمناسيب المعروفة. فحصت قطع الأثاث التخطيطية ضد 11 منطقة فتحة والأعمدة وحدود الأرضية وضد بعضها، وتحقق اتصال نقاط الحركة الرئيسية في مساحة صافية بعرض متر. التظليل الأزرق مسارات توضيحية وليس تصميمًا للأرضية. عدد المقاعد تقريبي، شامل السنتر بيس والبار. [تفاصيل المراجعة](review_checks.json).

الصور الواقعية للحوائط والدخلة مراجع بصرية مولدة لاختيار التنسيق؛ ليست رندرات من ملف SketchUp منفّذ. مخططات الفرش رسومات اختيار بمقاسات قطع تخطيطية، وليست رسومات تنفيذية. الحوائط الناقصة الظاهرة في صور العميل تُراجع وتُستعاد وفق الأصل قبل التنفيذ، ولا تُعتبر فتحات معمارية جديدة. لم يُعدّل أي ملف SketchUp أو إضافة RBZ في هذه المرحلة.

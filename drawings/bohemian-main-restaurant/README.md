# المطعم الرئيسي — بوهيمي مطابق لاتجاه اللوبي B1

[تحميل الإكستنشن RBZ](Ayaa_Main_Restaurant_Bohemian_Complete_Components_v1_0.rbz)

المطعم المقصود هو القاعة الكبيرة المكتوب عليها «مطعم رئيسي» في **lobby aya elshamy 3.dwg**، المحددة بالأحمر في صورة التحديد السابقة. المطعم المتخصص المجاور ليس ضمن هذا الفرش. ملف الأوتوكاد الأصلي لم يُعدّل.

## التشغيل وحفظ SketchUp

1. ثبّتي RBZ بدون فك الضغط من **Extensions > Extension Manager > Install Extension**. أعيدي تشغيل SketchUp إن لم تظهر القائمة.
2. افتحي **File > New** ثم **Extensions > Ayaa Bohemian Restaurant 1.0 > Build furnished MAIN restaurant and save SKP**.
3. بعد البناء تظهر نافذة حفظ **Ayaa_Main_Restaurant_Bohemian.skp**؛ احفظيه باسم جديد.
4. من نفس القائمة: **View PLAN** و**View 3D**، وإظهار/إخفاء السقف أو العمارة. السقف مخفي افتراضيًا لعرض الفرش. **Select complete furnishings** يحدد الفرش فقط للنقل أو النسخ إلى مشروع آخر.

كل كرسي وترابيزة وبنش ووحدة خدمة ونبات وإضاءة وديكور حائط Component كامل مستقل. القطع المتكررة Instances من تعريفات كاملة مشتركة لتخفيف الملف؛ **Make Unique** متاح إذا أردتِ تعديل قطعة واحدة وحدها. محتويات الترابيزة والكرسي ووحدة الخدمة ثابتة داخل بلوك القطعة؛ لا تحتاجين Explode لنقلها كاملة.

## التوزيع

**140 مقعدًا / 35 ترابيزة**: مجموعات لشخصين و٤ و٦، مع جلستين بنش، وحدتي خدمة وخزانة استقبال صغيرة ونباتات داخلية. خشب طبيعي وخوص منسوج وقماش أوف وايت وزيتوني وحجر دافئ ونحاس معتق، بنفس عائلة خامات آخر لوبي بوهيمي B1. الأثاث مخصص للطعام، مع طاولات بارتفاع 76 سم وكراسي طعام بارتفاع جلوس 49 سم.

الممرات المحجوزة داخل القاعة بعرض 1.8 م، مع فراغ إضافي خارج حدودها للجلوس. أقل مسافة بين مجموعات الجلوس بعد فحص إسقاط الهندسة الفعلية **1.32 م**. الفتحات الأصلية بعرضها في البلان، ومنها فتحة أضيق من الممر الداخلي؛ لم تُوسّع الأبواب الأصلية. فُحصت كل القطع مقابل الأبواب والأعمدة وحدود القاعة والممرات، ولم تظهر تداخلات.

الحوائط المصمتة مزودة بوحدات خوص وأقواس ونيشات خزف وأباليك موحدة، مع إبقاء فتحات الزجاج الظاهرة في البلان. وحدات الإضاءة كاملة بالتعليق والكانوبي، والمقاعد والطاولات والأصاري عند مستوى الأرض. الخامات والأجزاء الداخلية قابلة للتعديل.

## مطابقة المصدر وحدود الفحص

حدود القاعة مستخرجة من إحداثيات الحوائط الداخلية في DWG، والأعمدة من أشكالها الأصلية. بعض الأعمدة مرسومة نصفين حول مفصل زجاج ضيق؛ تجليدها ديكوري مستمر داخل نفس الغلاف، مع الاحتفاظ بقطع الأعمدة الأصلية. أُعيد إنشاء ارتفاعات العرض من البلان الثنائي؛ ارتفاع السقف المستخدم **3.6 م**، وجلسة النافذة 0.85 م ورأسها 2.95 م، وهي افتراضات عرض قابلة للتعديل وليست قياسات قطاع مرفق.

DWG لا يحدد INSUNITS؛ استُخدم المتر وفق عرض الأبواب وشبكة الأعمدة 8.4. الموديل قريب من نقطة الأصل لتجنب مشاكل الإحداثيات البعيدة؛ أصل إحداثياته في DWG هو **X=2190، Y=434**. مواقع القطع الداخلية واتجاه محاور البلان محفوظة نسبة إلى هذا الأصل.

تم فحص الممرات والمقاسات والهندسة وصياغة Ruby والأرشيف. **SketchUp Desktop غير متاح هنا، لذلك البناء والحفظ داخل التطبيق لم يُختبرا هنا.** الإضافة تنشئ الموديل داخل SketchUp وتستخدم حفظه الأصلي بدل كاتب SKP تجريبي.

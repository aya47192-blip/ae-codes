# إصلاح فحص المقاسات 1.4.2

[تحميل التحديث الكامل RBZ](../hotel-native-builder/Ayaa_Lobby_Components_v1_4_2.rbz)

1. ثبّتي ملف RBZ من **Extensions > Extension Manager > Install Extension** بدون فك الضغط.
2. اقفلي جميع نوافذ SketchUp وافتحيه مرة أخرى.
3. افتحي ملفًا جديدًا واختاري تحديدًا **Extensions > Ayaa Lobby 1.4.2**، ثم **BOHEMIAN V5** أو **GREEK COASTAL V4**.
4. احفظي SKP عند اكتمال البناء.

## الخطأ الذي أُصلح

الصورة الأخيرة تُظهر `Size/position check failed` للكرسي `NEW_RICH_boho_B1_Companion_0` بفرق **6.541326090366624 بوصة**. أمكن إعادة إنتاج هذه القيمة بالضبط من بيانات الحزمة الأصلية: كانت المقارنة تستعمل `instance.bounds`، وهو صندوق محيط لحدود التعريف وصناديق المجموعات المتداخلة بعد تدويرها، فيكبر حول الكرسي المائل. حدود المرجع مأخوذة من رؤوس الهندسة الفعلية، لذلك كانت المقارنة ترفض قطعة صحيحة.

الفحص الآن يمر على رؤوس الحواف داخل مجموعات القطعة ومكوناتها المتداخلة، ويطبّق تحويلاتها حتى إحداثيات الموديل، ويقارن حدود الهندسة الناتجة بالمرجع نفسه. حد السماح **0.004 بوصة لم يتغير** ولم يُلغَ الفحص. تبقى كل قطعة فرش Component مستقلًا.

راجعت الحساب العددي لكل مكونات الخيارات الأربعة، وأجريت اختبار Ruby على 39 قطعة فعلية من الحزمة، مع محاكاة واجهة التحويلات والمجموعات والمكونات. أكبر فرق في اختبار Ruby أقل من 10⁻¹² بوصة. هذا اختبار للحساب الجديد، وليس تنفيذًا لهندسة SketchUp داخل البرنامج. [نتائج الفحص](verification.json) · [اختبار Ruby](test_geometry_bounds.rb).

كل بيانات التصميم والخامات مطابقة للإصدار السابق، وإصلاح UI.refresh محفوظ. لا تغييرات تصميم جديدة في هذا التحديث. [معاينة التصميمات](../hotel-distinct-update-1-4/DISTINCT_LOBBY_PREVIEW.pdf). الحزمة تنشئ SKP داخل SketchUp؛ ليست SKP جاهزًا. SketchUp Desktop غير متاح هنا لاختبار التشغيل الكامل.

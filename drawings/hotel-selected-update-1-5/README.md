# اللوبي — الساحلي والبوهيمي B1، إصدار 1.5.0

[تحميل الإضافة الكاملة RBZ](../hotel-native-builder/Ayaa_Lobby_Components_v1_5_0.rbz) · [معاينة الموديلين PDF](SELECTED_LOBBIES_PREVIEW.pdf)

## التشغيل

1. نزّلي RBZ بدون فك الضغط.
2. SketchUp: **Extensions > Extension Manager > Install Extension** واختاري الإصدار 1.5.0.
3. اقفلي كل نوافذ SketchUp وافتحيه مرة ثانية، ثم افتحي ملفًا جديدًا.
4. اختاري **Extensions > Ayaa Lobby 1.5.0**، ثم **Build BOHEMIAN B1** أو **Build GREEK COASTAL**.
5. احفظي SKP بعد اكتمال البناء. اعملي كل أوبشن في ملف جديد منفصل؛ كل قطعة Component كامل مستقل، ولا تحتاج Explode.

الخيارات السابقة للمودرن محفوظة كما هي. نفس إصلاحات UI.refresh وفحص الحدود الدقيقة للهندسة من الإصدار 1.4.2 محفوظة بدون تغيير. لم يتوفر SketchUp Desktop للاختبار الفعلي؛ تم فحص Ruby والحزمة والبيانات المصدرة والخامات والحدود والمقاسات والتداخلات والفتحات ومسارات الوصول. [نتائج المراجعة](verification.json).

الصور في PDF مرندرة من نفس الموديلين المصدرين للحزمة، وليست صور mood board. تخطيط الفرش يتبع مناطق وترتيب الصورة الأوتوكاد المرجعية؛ لا توجد أبعاد CAD مصدرية لهذه الصورة لضمان نقل مساحي حرفي. البناء الأصلي و598 هندسة مصدر و22 عمودًا محفوظة، مع إظهار القطاعات الأصلية للأعمدة لإغلاق وصلات الحوائط والشبابيك. لكل ستايل 46 مقعدًا و15 أبليكًا موحد الشكل، وخمس تجميعات أبواب محفوظة. الحوضان مزروعان بالكامل بتغطية كثيفة. مناطق الأرضية متجاورة على منسوب واحد، والسنتر بيس يحافظ على منسوبه ودرجاته الأصلية؛ الباترن البوهيمي حجري هندسي ظاهر.

صُححت تعيينات خامة 32 لوح زجاج أصلي في كل نسخة حتى لا تظهر الألواح مصمتة. وأضيفت قطع سيراميك نحتية بين الفازات والكتب لتفادي تكرار نفس المفردة في وحدات العرض.

## الفتح الصحيح

1. نزّلي ZIP إلى جهازك.
2. كليك يمين عليه → **Extract All / استخراج الكل**.
3. افتحي **SketchUp 2023** ثم **File → Open** واختاري ملف `.skp` المفكوك. لا تفتحي رابط SKP الخام داخل المتصفح.
4. بعد الفتح اضغطي **Shift + Z (Zoom Extents)** لعرض كل البلوكات، أو اختاري مشهد Exterior.

كل بلوك Component مستقل يمكن تحديده وتحريكه ونسخه إلى مشروع آخر. توجد مشاهد Interior لإظهار الفرش مع إخفاء السقف. ترتيب البلوكات: 01–02 سبا، 03–04 جيم، 05–06 مطعم، 07–08 كافيه، 09–10 شاليه، 11–12 وحدات بحرية، 13–15 سنتر بيس، 16 Kids Area.

هذه إعادة تغليف للنسخ المجمّعة الموجودة، دون تعديل التصميم. إعادة تصميم قشور السمك كمبنى واحد متصل لكل استخدام ما زالت قيد العمل، وهذه الروابط لا تدّعي أنها النسخة المعدّلة.

تم فحص CRC وبصمة ملف SKP داخل كل ZIP ومطابقتها مع النسخ المقروءة هندسيًا. ملفات SKP بصيغة v17؛ الهدف SketchUp 2023. لم يتوفر SketchUp Desktop لاختبار الفتح التفاعلي. المقاسات مقترحة، ولم تُعدّل ملفات الموقع الأصلية.

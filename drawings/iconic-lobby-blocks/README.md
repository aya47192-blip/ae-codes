# قطع كبيرة للسنتر بييس — الساحلي والبوهيمي

[تحميل الإكستنشن RBZ](Ayaa_Iconic_Coastal_Bohemian_20_Blocks_v1_0.rbz)

**٢٠ قطعة مستقلة: ١٠ ساحلي و١٠ بوهيمي.** المجموعة منفصلة عن ملفات اللوبي، وتضيف فقط. كل قطعة بما فيها القاعدة والزرع أو الملحقات Component واحد كامل، ويمكن فتحه لتعديل التفاصيل. الأبعاد أدناه بالمتر؛ الإضافة تبنيها بالحجم الحقيقي.

## التركيب والاستخدام

1. نزّلي RBZ كما هو، بدون فك الضغط، ثم **Extensions > Extension Manager > Install Extension**.
2. افتحي **Extensions > Ayaa Iconic Blocks 1.0**. لو القائمة لم تظهر، أعيدي تشغيل SketchUp.
3. **Browse catalogue - preview / place ONE** يفتح كتالوج العشرين قطعة. اختاري القطعة ثم اضغطي داخل الموديل لوضعها؛ Esc يلغي الوضع. ويمكن الإدراج من قائمتي **Place ONE** مباشرة.
4. **Build ALL 20 - independent components** يعرض العشرين في شبكة متباعدة. افتحي **File > New** إذا أردتِ مكتبة منفصلة، ثم احفظيها SKP وانقلي القطع بالنسخ واللصق. عند التشغيل داخل موديل موجود تُضاف الشبكة إلى جانبه، دون حذف عناصره.
5. **Build COASTAL 10** أو **Build BOHEMIAN 10** يعرض مجموعة واحدة. كل قطعة باسم وكود واضحين في Outliner وEntity Info، مع Tag لكل ستايل. لا تحتاجين إلى Explode لنقل القطعة كاملة.

القطع بدائل للاختيار، وليست جميعها مخصصة للوضع معًا داخل السنتر بييس. اختاري قطعة رئيسية أو مجموعة محدودة بحسب المساحة وخطوط الحركة. لا تغيّر الإضافة السنتر بييس أو الزرع الحالي تلقائيًا.

# إعادة تصميم اللاندسكيب — الصدفة المروحية

النسخة الأحدث تعيد تقسيم المسطحات المفتوحة المتاحة حول المبنى الأوسط كتكوين لاندسكيب متصل، بدل الالتزام بحدود الجيوب المثلثة والرباعية السابقة. التكوين مستمد من ضلوع الصدفة المروحية ويربط المسارات والزرع والجلسات، مع اعتماد تصميم الحديقة الوسطى السابق أساسًا للتكوين.

- [فتح PDF النسخة الجديدة](resort_plan_continuous.pdf)
- [فتح الصورة](resort_plan_continuous.png)
- [تنزيل الصورة والـPDF داخل ZIP](resort_plan_continuous.zip)

للتنزيل من GitHub اضغطي Download raw file أو السهم لأسفل. بعد تنزيل ZIP استخدمي Extract All.

الـPDF يحتوي صورة التصميم بجودتها الأصلية، وليس رسم CAD أو PDF متجهيًا. التصميم تصور بصري للمراجعة، ولم تُتحقق المطابقة الرقمية لكل خط أسود مع مخطط الموقع الأصلي.

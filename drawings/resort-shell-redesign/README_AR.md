# تصور إعادة تصميم اللاندسكيب — الصدفة المروحية

النسخة الأحدث لتعديل الجيوب الجانبية حول الحديقة الوسطى، باستخدام مفهوم الصدفة المروحية.

- [فتح ملف PDF](resort_plan_latest.pdf)
- [فتح الصورة الأصلية](resort_plan_latest.png)
- [تنزيل الصورة والـPDF داخل ZIP](resort_plan_latest.zip)

للتنزيل من GitHub اضغطي Download raw file أو السهم لأسفل، ثم فكّي ضغط ZIP بـ Extract All.

الـPDF يحتوي صورة التصميم بجودتها الأصلية، وليس رسم CAD أو PDF متجهيًا. التصميم تصور بصري للمراجعة، ولم تُتحقق المطابقة الرقمية لكل خط في مخطط الموقع الأصلي.

# البلانات الـ٢١ مع أيقونة الكونسبت

أُضيفت أيقونة صغيرة للعنصر الطبيعي واسم الكونسبت بجوار كل بلان، في المساحة البيضاء أعلى يمين الصفحة. بقي مقاس الصفحة وحجم البلان وهندسته كما هي؛ الأيقونات مستقلة عن الرسم الأصلي.

- [تحميل جميع البلانات مع الأيقونات — PDF](all_21_outline_with_icons.pdf)
- [PDF منفصل لكل بلان مع الأيقونة — ZIP](individual_outline_with_icons.zip)
- [دليل الأيقونات والكونسبتات — PDF](concept_icon_legend.pdf)

داخل ملف ZIP توجد ٢١ صفحة PDF مستقلة بأرقام الأوبشنات السابقة، بالإضافة لدليل الأيقونات وهذا الشرح. الأيقونات بالأسود والأبيض، واسم كل مفهوم بالعربية والإنجليزية.

نسخ الـoutline الأصلية محفوظة في `../resort-outline-all/` ولم تُستبدل. فُحصت الصفحات للتأكد من أن التغيير محصور داخل مساحة الأيقونة والعنوان، دون تغيير رسم البلان أو مقياسه.

هذه ملفات عرض PDF تحتوي صور الـoutline والأيقونات؛ ليست ملفات CAD قابلة للتحرير، ولا تضيف أبعادًا تنفيذية جديدة.

للتنزيل من GitHub افتحي الملف واضغطي **Download raw file ⬇️**، أو استخدمي رابط التنزيل المباشر. بعد تنزيل ZIP استخدمي **Extract All**.

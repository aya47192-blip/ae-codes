# اللوبي 1.4 — إعادة التوزيع والريسبشن والحوائط + إصلاح التشغيل

[تحميل التحديث RBZ](../hotel-native-builder/Ayaa_Lobby_Components_v1_4_0.rbz) · [معاينة التصميمين PDF](DISTINCT_LOBBY_PREVIEW.pdf)

## التركيب والتشغيل

1. نزّلي ملف RBZ كما هو، بدون فك الضغط.
2. Extensions > Extension Manager > Install Extension، واختاري ملف 1.4.0.
3. اقفلي كل نوافذ SketchUp وافتحيه مرة أخرى.
4. في ملف جديد اختاري **Extensions > Ayaa Lobby 1.4**، ثم **Build BOHEMIAN V5** أو **Build GREEK COASTAL V4**.
5. احفظي ملف SKP بعد انتهاء البناء. كل قطعة Component مستقل واللوبي مفروش بالكامل.

القائمة الجديدة لها اسم ومسار تحميل وRuby module مستقلون، لتجنب تنفيذ كود النسخة القديمة المحمّل في الذاكرة. لا يوجد استدعاء UI.refresh في أي ملف Ruby بالحزمة؛ تحديث العرض يتم عبر active_view مع التحقق من توفر الدالة. لا تحتاجين Ruby Console. الإضافة تنشئ SKP داخل SketchUp، وليست SKP جاهزًا للتنزيل. خيارات المودرن السابقة موجودة أيضًا.

## التصميم

البوهيمي: 47 مقعدًا، مع ركنة عائلية وكنبتين متقابلتين وجلسة هلالية ومجموعة نقاش من ستة كراسي وركن قراءة وبوفات ومكتبة خلفية متكاملة. لم يعد توزيعه سلسلة من جلسات الأربع كراسي المتشابهة.

الساحلي: 55 مقعدًا، مع بانكيت طولي وخدمته بطاولتين، وطاولة اجتماعية لثمانية أفراد، وركنة وجلسة انتظار وجلسات أخرى مختلفة عن البوهيمي. الريسبشن القديم المكوّن من وحدتين بيضاويتين استُبدل بكونتر حجري واحد متصل مع جزء منخفض. الحائط الخلفي بالكامل تصميم حجر وأقواس سطحية مع أعمال سيراميك بارزة؛ الحائطان الجانبيان المصمتان أيضًا لهما معالجة كاملة الارتفاع. الأقواس تشطيب مضاف على الحائط وليست فتحات معمارية جديدة.

كل الأبواب والشبابيك ومواقع الأعمدة والمناسيب محفوظة. لم تتغير أرضيات 1.3 أو السنتر بيس المعتمد. فُحصت بيانات الهندسة والخامات وحدود القطع و11 منطقة فتحة، ولم تُرصد تداخلات فرش أو اعتراض للفتحات أو الأعمدة. فُحصت سلامة الحزمة وصياغة Ruby. الصور مرندرة من الموديل نفسه. تشغيل النسخة داخل SketchUp نفسه غير متاح هنا ولم يُختبر؛ [تفاصيل الفحص](verification.json).

# Gewan / shell option 1 / local correction V3

**V3 replaces rejected V2.** The global smoothing in V2 exceeded the user’s intended scope.

[Closed-region AutoCAD DXF](Gewan_Shell_Closed_Regions_v3.dxf) · [U building and lower layout comparison](CAD_v3_Restored_U_and_Lower.pdf) · [Full package](Gewan_Shell_Option1_Local_Repair_v3.zip)

استُعيد المبنى U والمنطقة الوسطى والسفلية من هندسة ما قبل التنعيم العام. بقي تصحيح المنحنيات داخل مجموعات الشاليهات فقط، مع تحويل قوسين في بروزات المبنى الرئيسي إلى رجوعات مستقيمة حادة. ١٥٨ مسارًا محميًا لم يتغيّر، و١٢٨ قطعة من محيط المبنى U بقيت كما هي.

١٣٣ مساحة مغلقة و٣٥ ثقبًا؛ الوحدة مليمتر، والدائرة المرجعية قطرها ٢٥ متر. اجتاز DXF إعادة القراءة وAudit، ونجح تكوين ١٣٣ وجهًا من الملف النهائي وقراءتها دون حواف سائبة. لم يختبر استيراد SketchUp Desktop أو AutoCAD Desktop.

# دليل مبدئي لخامات الواجهات

[تحميل PDF العربي](Facade_Materials_Preliminary_Guide_AR.pdf) · [الجدول CSV](Facade_Materials_Comparison_AR.csv) · [النص الكامل](Facade_Materials_Notes_AR.md)

يغطي 16 عائلة خامات، وأنظمة التركيب والشمس والرطوبة والأملاح والحريق، وتقنيات حديثة والاستدامة، وتنسيق الطرز ووظائف المباني.

**التحقق من الإنترنت لم يكتمل:** المواقع الفنية محجوبة في هذه البيئة برد 403. لم تُقرأ الكتالوجات والمراجع المقترحة في الجلسة. الملف معرفة فنية عامة مرتبة، وليس مواصفة تنفيذية أو اعتماد منتج. source_status.json يوثّق حالة الوصول، وروابط المصادر المقترحة موسومة بأنها غير مقروءة.

التكلفة مقارنة نوعية، وليست أسعار سوق حديثة. يلزم تحديد الموقع والطراز والارتفاع ونظام الحائط ثم الحصول على تقارير المنتج والمراسي والحريق والضمان والتفاصيل قبل اعتماد نهائي.

لوبي الفندق — المودرن المصحّح

الحزمة تحتوي hotel_modern_corrected_v5.dae ومجلد textures. هذا ملف DAE للاستيراد في SketchUp وليس SKP مكتوبًا من الخارج.

الطريقة العادية: فكّي كل حزمة في مجلد منفصل بالكامل، ثم File > Import > COLLADA، واستوردي DAE مع إبقاء textures بجواره. فعّلي Shaded with Textures لإظهار الخامات ثم احفظي SKP.

للاستيراد والتحويل إلى Components والحفظ كـSKP تلقائيًا: افتحي مشروعًا جديدًا في SketchUp Desktop، ثم Ruby Console واكتبي:
load UI.openpanel('Choose create_skp.rb', nil, '*.rb')
واختاري create_skp.rb الموجود بجوار ملف DAE. سيستورد النموذج بخاماته، ويحوّل مجموعات NEW_ الكاملة إلى Components، ويفك حاويات الطبقات دون تفكيك قطع الأثاث، ويحفظ ملف hotel_modern_corrected_v5.skp في نفس المجلد. لو الاسم موجود سيستخدم رقم نسخة جديدًا حتى لا يستبدل ملفًا سابقًا. اختاري هذه الطريقة أو الاستيراد العادي؛ لا تنفذيهما معًا في نفس المشروع حتى لا تتكرر النسخة.

البناء والفتحات وأجسام الأعمدة والمناسيب محفوظة. السنتر بيس مرتفعة بدرجتين .22/.39/.56 م، والمدخل بدرجة .22/.3065 م. الأحواض الثابتة لم تُنقل.
لوح المراية القديم والزخرفة المعدنية المتموجة والقطعة والنباتات الغريبة للسنتر بيس أزيلت واستبدلت. أحواض الزرع الجديدة صلبة ومفتوحة وفيها تربة وأوراق بيضاوية وسيقان.

لم يتوفر SketchUp Desktop هنا لتجربة الاستيراد أو تشغيل Ruby أو إنشاء SKP أصلي. جرى فحص DAE بإعادة قراءته، والخامات، والتجميع، واتجاهات الأرضيات، والتقاطعات والفتحات. المساعد يستخدم SketchUp Ruby API لإنشاء SKP على جهازك.

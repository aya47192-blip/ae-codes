# المطعم البوهيمي — توزيع جديد V3

نسخة جديدة مستقلة على حدود المطعم الأصلية، بفرش أصغر ومجموعات منظمة: **٢٩ ترابيزة لشخصين، ٢٩ لأربعة، وترابيزتان لستة = ١٨٦ مقعدًا / ٦٠ ترابيزة**. الركنيات الثلاث تتبع حوائط المثلثات؛ كل ركنية تخدم ترابيزتين منفصلتين لأربعة، والركنية الوسطى أقصر بجوار الباب للمحافظة على فتحته. يوجد أيضًا ركنيتان صغيرتان في الملحق وجلسات بنش حائطية.

- [تحميل نسختي DXF](Ayaa_Restaurant_Mixed_AutoCAD.zip): ملف COLOR بخامات وألوان واضحة، وLINEWORK بخطوط بدون تعبئة. نفس توزيع البلوكات في النسختين، إصدار DXF R2004. لا يوجد DWG في هذه النسخة، بناءً على تأكيد فتح DXF لديك.
- [تحميل SketchUp والإكستنشن المستقل](Ayaa_Restaurant_Mixed_SketchUp.zip): ملف SKP مباشر + RBZ اختياري منفصل عن الإضافات القديمة.

## الفتح

حمّلي ZIP ثم اختاري Extract All. افتحي ملف SKP من SketchUp باستخدام File > Open. لا يحتاج ملف SKP إلى تثبيت إكستنشن.

لبناء نسخة باستخدام SketchUp نفسه بدلًا من فتح SKP: افتحي ملفًا جديدًا فارغًا، ثم Window > Extension Manager > Install Extension واختاري ملف RBZ بعد فك ZIP. من قائمة Extensions اختاري **Ayaa Bohemian Restaurant MIXED 3.0** ثم Build. توجد أيضًا أداة مستقلة في شريط الأدوات. لا تختاري ZIP في مدير الإضافات.

للأوتوكاد: افتحي COLOR.dxf للعرض أو LINEWORK.dxf للطباعة؛ احفظيه من داخل AutoCAD بصيغة DWG إذا احتجتِها. الوحدات بالمتر، والمواقع تحتفظ بمرجع البلان الأصلي (2190,434). كل قطعة فرش بلوك مستقل، وطبقة AYAA_M3_FLOOR_DECOR مستقلة. زخارف الأرضية مخفية افتراضيًا في نسخة الخطوط، ويمكن إظهارها من Layers.

## ما تم التحقق منه وحدود الفحص

- ثبات حدود العمارة وتحويلات المكوّنات دون تمديد أو تشويه؛ أرضية الأساس لم تتغير، والزخارف ١١ بلوكًا مستقلًا فوقها.
- فحص مواقع الفرش الفعلية ضد الأعمدة والأبواب والممر الرئيسي: لا تداخلات مسجلة. الممر الرئيسي ١٫٨ م، وفحص اتصال الحركة الفرعية بعرض يقارب مترًا (٠٫٩٩ م). هذه ليست مراجعة اعتماد للكود المحلي أو مخارج الطوارئ.
- ٥٥ وحدة حائط وإضاءة محفوظة بتثبيتها واتجاهها من النسخة المراجعة؛ لا تداخل مع الفرش في فحص ثلاثي الأبعاد محافظ.
- DXF: صفر أخطاء وإصلاحات في القراءة، و٣٣٨ INSERT متطابق الموضع والاتجاه مع النموذج؛ الفرش كامل بدون خطوط مفككة في Modelspace.
- SKP: تمت إعادة قراءته، ٤٤٧ مكونًا و١٦٥ تعريفًا، والخامات والصور مضمّنة، ولا توجد أوجه مفكوكة عند جذر النموذج. السقف مخفي عبر Tag مستقل.
- RBZ: فحص صياغة Ruby 3.1 وسلامة الأرشيف. الفحوص برمجية؛ **لم يتم اختبار الفتح داخل AutoCAD أو SketchUp Desktop هنا**.

العدد أقل من النسخة السابقة لإتاحة الجلسات الثنائية والحفاظ على الحركة؛ لم يُستخدم حاصل قسمة المساحة الإجمالية كعدد إلزامي للمقاعد.

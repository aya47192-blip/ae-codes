# تعديل السلحفاة وأربعة بدائل ساحلية

هذه المجموعة تستكمل نفس مخطط القرية ونفس أسلوب اللاندسكيب، مع توجيه التصميم إلى تنظيم أوضح في الوسط وكتل زرع أكبر على الشمال. خيارات الصدفة والسلحفاة السابقة محفوظة في مجلداتها.

| الرقم | العنصر الطبيعي | ترجمته في التقسيم |
|---|---|---|
| 02 المعدّل | درع السلحفاة البحرية | خلايا وسطية وخلايا جانبية حول محور، وممرات بين الخلايا |
| 03 | نجم البحر | نقطة تجمع وسطية وخمسة اتجاهات حركة تربط غرف اللاندسكيب |
| 04 | قوقعة النوتيلوس | التفاف متدرج وحجرات منحنية ومسطحات مائية هلالية |
| 05 | المرجان المتفرع | مسار رئيسي وتفرعات عضوية تربط كتل الزراعة والفراغات |
| 06 | قرص قنفذ البحر المسطح Sand Dollar | خمسة أشرطة بيضاوية مزدوجة حول مركز مائي وحركة محيطية |

نجم البحر يعتمد على أذرع الحركة، بينما قرص قنفذ البحر يعتمد على الأشرطة البيضاوية المزدوجة؛ لكل بديل مصدره الطبيعي المستقل.

من صفحة الملف على GitHub اضغطي **Download raw file ⬇️**. بعد تحميل ZIP استخدمي **Extract All**.

هذه دراسات كونسبت بصرية؛ ملفات PDF تحتوي صور التصميم، وليست رسومات CAD تنفيذية. استُخدمت قاعدة الموقع القائمة كمرجع ثابت للمباني والطرق، لكن المطابقة الرقمية لكل خط أسود لم تُتحقق. التناظر يخص التنظيم الداخلي للحديقة، دون محاولة تماثل حدود الموقع غير المنتظمة.

## طريقة الاختيار

C0 هو المقعد الدائري حول الزرع في منتصف اللوبي، مرجع ثابت من صورة المستخدم. يضبط موضعه ومقاسه لاحقًا على البلان.

| الفئة | البدائل |
|---|---|
| الجلسات والكراسي | S1 منحنية، S2 مستطيلة بحواف لينة |
| الترابيزات | T1 حجر وخشب، T2 قاعدة هندسية مجسمة |
| الريسبشن وخلفيته | R1 منحني، R2 هندسي بتفاصيل إسلامية |
| كسوات الأعمدة | P1 الأقرب للصورة، P2 تشبيك إسلامي أغنى |
| النجفة المركزية | L1 |
| معلقات الريسبشن | L2 |
| الأباليك | A1 أو A2 |
| الحوائط والبراويز والنيشات | W1 خشب، W2 حجر ونيشة بعقد |
| زخرفة الأرضية الدائرية | F0 كعنصر مستقل عن أرضية مستمرة |

يمكن تركيب الاختيارات معًا، مثل S1 + T2 + R1 + P1 + A2 + W1/W2. الاختيارات صور تصميم مولدة للمراجعة وليست كتالوج منتجات مصنع، وليست هندسة نهائية معتمدة أو بلوكات جاهزة. PDF ثلاث صفحات A3 أفقية يحتوي صور اللوحات؛ ليس رسومات متجهة أو مخطط إضاءة تنفيذيًا.

## نطاق التنفيذ المسجل بعد اختيار المستخدم

- مصدر CAD يحدد أماكن الرصة فقط؛ لا تنسخ أشكال أثاثه أو طرازه. يلزم تحديد ملف الكاد الفعلي والنسخة الصحيحة قبل بناء الموديل؛ لم تجرِ معايرة أو مطابقة البلان بهذه الصور.
- الحفاظ على العمارة الأصلية والفتحات والمحاور ومسارات الحركة، مع التحقق من المقاس الفعلي للسقف والأعمدة والحوائط.
- أثاث وإضاءة وديكور بعمق وهندسة فعلية ومكونات مستقلة قابلة للتحريك والاستبدال؛ الزخارف المهمة مجسمة وليست صورة مسطحة بديلة عن المجسم. خامات مضمنة، حواف نظيفة وتنعيم مناسب دون حذف الحدود الضرورية.
- زخرفة F0 في مستوى مناسب بصريًا مع فصلها كمكوّن مستقل؛ تحتها أرضية أساسية كاملة دون ثقوب عند إخفائها. لا وجوه متطابقة في المستوى تسبب وميضًا، ولا درجة بارزة غير مقصودة. الرسم التفجيري توضيح للفصل الرقمي وليس اقتراح عتبة حجرية مرتفعة.
- كل أبليك بقاعدة تثبيت مطابقة لمستوى الحائط واتجاه عمودي صحيح؛ المعلقات لها قاعدة سقف وتعليق يصل للسقف. مراجعة التحويلات والـnormals والتداخلات والارتفاعات من الملف النهائي، لا من الرندر وحده.
- الإضاءة العامة/المهمة/الزخرفية منفصلة في التوزيع. إنشاء مصادر ضوء فعالة يتطلب محرك الإظهار الذي سيستخدم فعليًا؛ مجرد خامة مضيئة في SketchUp لا تساوي مصدر ضوء فوتومتريًا.
- توزيع نقاط الإنارة والسويتشات والدوائر والأحمال والإضاءة الطارئة والتحقق من lux والوهج يحتاج مقاسات ومناسيب وبيانات IES/LDT/لومن وقدرة للوحدات، والكود الكهربائي المناسب. لا يمكن اعتماده كهربائيًا من moodboard. لا ادعاء بحساب كهرباء أو دقة مليمترية أو تطابق 100% قبل توفر بيانات المصدر والفحص.
- بعد الاختيار: تثبيت مرجع كل قطعة وواجهاتها ومقاساتها وتفاصيلها، ثم التنفيذ والمقارنة. الصور الفردية لا تحدد الظهر والأجزاء المخفية أو كل الأبعاد.

الحالة: بدائل للاختيار فقط؛ لم تُنشأ نماذج ثلاثية الأبعاد لهذا الأوبشن ولم يعتمد المستخدم اختياراته بعد.

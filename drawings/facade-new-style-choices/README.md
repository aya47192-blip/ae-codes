# بدائل جديدة لتصميم الواجهة

المقترح الرومانيسكي السابق رُفض لأنه بقي قريبًا من هيئة المبنى الأصلي. هذه معاينات تصورية جديدة لاختيار الاتجاه قبل تنفيذ كاد جديد.

A: تيودور إحيائي Tudor Revival.
B: تعبيري بارامتري Parametric Expressionism.
C: تفكيكي Deconstructivism.

تتضمن المعاينات تغييرًا في نهايات البرج والأسقف والمدخل والبلكونة وتشكيل الجناح المصمت. مواضع الفتحات والتفاصيل مرجعية مبدئية، وتحتاج ضبطًا هندسيًا على ملف المصدر بعد اعتماد الاتجاه. الصور تصورية مولدة وليست رسومات كاد منفذة.

# مراجعة حركة مطعم آية

- [تحميل التقرير PDF](Restaurant_Circulation_Review.pdf)
- [القياسات على البلان](01_Measured_Circulation.png)
- [اقتراح ربط الحركة](02_Suggested_Circulation.png)

تمت قراءة ملف DWG المرسل وتحويل نسخة منه للتحليل، دون تعديل الأصل.
الملف يحتوي على 284 كرسيًا منفصلًا و14 كنبة ركنية و80 ترابيزة. سعة الكنبات ليست محسوبة كعدد أشخاص نهائي.
الأرقام بحسب حدود الفرش المرسوم وأغلفة مجموعات الجلوس، وليست بعد سحب الكراسي. توجد اختناقات عند الأعمدة لا يوضحها قياس المسافات بين الصفوف وحده.
اقتراح النقل يحدد مجموعة ستة أفراد واحدة كخطوة أولى؛ يحتاج المسار العرضي أيضًا إلى توسيع حول الأعمدة. موضع النقل مبدئي ويتطلب ضبط الوصول وحركة الأبواب. التقرير مراجعة حركة أولية وليس اعتماد إخلاء أو إتاحة.

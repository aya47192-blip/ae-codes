# المجموعة الساحلية الثانية — أربعة بدائل جاهزة

هذه المجموعة تضم الأربعة بدائل التي اكتمل إخراجها. اختلاف كل بديل في تنظيم الحركة وهندسة الكتل، وليس في الألوان فقط.

لم يكتمل إخراج البديل الخامس (الدلتا الساحلية) أو تصحيح الشمال في السلحفاة، بسبب خطأ تقني من أداة الرسم: `Unknown parameter: reasoning`. لم تُستبدل صورة السلحفاة القديمة ولم يُقدّم أي ملف على أنه تعديل مكتمل.

| الملف | مصدر الكونسبت | أسلوب التقسيم |
|---|---|---|
| 07 — المانجروف | عروق ورقة المانجروف | عرق رئيسي وفروع مائلة وغرف زرع طويلة |
| 08 — المرجان المخّي | الحواف والطيات المتصلة لسطح المرجان المخّي | شرائط زرع مطوية وممرات بين الطيات مع وصلات عرضية |
| 09 — خياشيم السمكة | الصفائح المتكررة المتصلة بمحور الخيشوم | إيقاع من الشرائط المقوسة المتوازية حول مسار رئيسي |
| 10 — الموج | تعاقب قمم الموج وقيعانه | جبهات منحنية ممتدة ومسطحات مائية بين الكتل |

المرجان المخّي يختلف عن المرجان المتفرع في المجموعة السابقة: المرجع هنا طيات مستمرة، وليس شبكة أذرع. والموج يستخدم منحنيات ممتدة مفتوحة بدل الطيات المرتدة.

الحزمة تضم صور PNG وPDF منفصلًا لكل تصميم، وملف المقارنة وهذا الشرح. ملفات الخيارات السابقة محفوظة دون استبدال.

للتنزيل من GitHub افتحي الملف واضغطي **Download raw file ⬇️**. بعد تنزيل ZIP استخدمي **Extract All**.

هذه تصورات كونسبت بصرية، وليست رسومات تنفيذية أو ملفات CAD. استُخدمت قاعدة الموقع الحالية مرجعًا للمباني والطرق؛ لم تُتحقق المطابقة الرقمية لكل خط أسود. ملفات PDF تحتوي صور المقترحات. يلزم ضبط الأبعاد وعروض المسارات والمناسيب على قاعدة CAD قبل التنفيذ.

# استدامة مع الحفاظ على شكل الواجهة — V2

هذه النسخة تصحّح المعالجة السابقة التي حوّلت العقود والبروزات إلى مستطيلات. رجعت العقود والفتحة الوسطى الكبيرة وبروز مظلة المدخل والجزء العلوي الأوسط ونسب إطارات المظلات أقرب إلى الأصل، مع توظيف الحقول القديمة بدل تركها فارغة. لا يوجد زرع.

## إيه فضل وإيه اتغير؟

| العنصر الأصلي | المعالجة الجديدة |
|---|---|
| الشبابيك المعقودة | الاحتفاظ بالعقود والزجاج بكامل الارتفاع، مع براويز عزل بسيطة وتقسيمات زجاج أقل. أُلغيت حشوات الرؤوس المستطيلة من النسخة السابقة. |
| الفتحة الوسطى الكبيرة | أُعيد رسم محيطها بالأقواس الدائرية الأصلية من ملف المصدر. |
| مظلات النقوش والتغطيات المتكررة | ست مجموعات لوفرات تظليل داخل نفس الحقول، مع الاحتفاظ بأرجل الإطارات وبروزها العام. |
| الأعمدة الصغيرة بين الشبابيك المزدوجة | أربع زعانف رأسية للتظليل بدل الحليات، مع إعادة قواعد النوافذ المشتركة. |
| حشوتا الزخارف أعلى الواجهة | حقلان من الخلايا الشمسية المدمجة BIPV في نفس مواضع الحشوات. |
| الروزتة الدائرية | فتحة خدمة/عادم بلوفر أفقي في نفس المركز بدل النقش. |
| التاج العلوي المنحني | شاشة تهوية بنفس منحنيات المصدر الرئيسية. |
| مظلة المدخل المنحنية | الاحتفاظ بمحيطها وبروزها، وإدخال وحدات BIPV مستطيلة منفصلة داخل وجهها. الألواح الصلبة منفصلة ولا يُدّعى ثنيها على المنحنى. |
| الكرانيش الجانبية | أشرطة تظليل وتهوية في نطاق البروزات الأصلية. |
| شرائط الحليات الحجرية | كسوة مقترحة بفراغ تهوية في نفس الشرائط الضيقة. |
| السقف | الحفاظ على منسوب غطاء السقف، مع أربع مجموعات ألواح شمسية منخفضة فوقه ومجرى تجميع مياه. |

الرسمة دراسة تأهيل: الاحتفاظ بالشكل العام لا يعني نسخ كل الحليات أو تقسيمة الزجاج السابقة أو مطابقة كل تفصيلة تنفيذ. الأدوار البيئية للعناصر مقترحة وتتطلب مسارات تهوية وتثبيت وخدمات مناسبة عند التنفيذ.

## جودة ملف الكاد

الهندسة أصلية قابلة للتحرير، وليست صورة ملصقة أو تتبعًا للبكسلات. الأقواس عناصر ARC دائرية حقيقية. الخطوط Continuous بسمك موحد 0.25 مم ولون ACI 7، أسود على الورق الأبيض وأبيض على خلفية الموديل الداكنة.

فحص نهايات العناصر مقابل الخطوط والأقواس التحليلية سجل صفر نهايات حرة، بما يشمل نهاية خط متصلة بمنتصف قوس. فُحصت الأطوال الصفرية والتكرارات الخطية والأقواس المتطابقة، وتدقيق DXF خالٍ من الأخطاء والإصلاحات. أعيد تحويل DWG إلى DXF ومقارنة الإحداثيات ومعاملات الأقواس وأعلام إغلاق البوليلاين. ## حدود الاستخدام

هذه ليست تفاصيل تنفيذ إنشائية أو شهادة أداء بيئي. اتجاه الشمس والمناخ ومسارات الهواء ونوع الزجاج وميل الألواح والتثبيت والصرف تحتاج تنسيقًا فنيًا. حُفظ مقياس إحداثيات المصدر دون تحويل وحدات، ويلزم تأكيد الوحدة الفعلية قبل التنفيذ. Autodesk AutoCAD المكتبي غير متاح هنا؛ تم فحص DWG بأدوات CAD مستقلة وإعادة قراءة هندسته.

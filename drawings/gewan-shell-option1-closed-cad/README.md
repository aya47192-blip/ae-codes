# Gewan — Geometric Shell Option 1 / AutoCAD DXF

[Closed regions DXF — start here for SketchUp](Gewan_Shell_Option1_Closed_Regions.dxf) · [Full AutoCAD package](Gewan_Shell_Option1_AutoCAD.zip) · [CAD preview PDF](Gewan_Shell_Option1_Review.pdf)

المعتمد: الأوبشن الأول **بدون البولات الخاصة الصغيرة**. ١٢ شاليه، مع الحفاظ على المنطقة المركزية والسفلية واللسانين. الوحدة مليمتر، قطر دائرة الدوران الكبيرة أسفل اليسار ٢٥ متر.

- **Closed_Regions.dxf**: ١٣٣ مساحة مغلقة و٣٥ حدًا داخليًا؛ الحدود المشتركة مكررة عمدًا كي تكون كل مساحة مستقلة.
- **Shared.dxf**: الحدود المشتركة مرة واحدة، دون حواف مكررة أو نهايات غير متصلة.
- **Chalets_Only.dxf**: الشاليهات الاثنا عشر بمحيطات مغلقة.

اجتازت ملفات DXF إعادة القراءة وAudit دون أخطاء أو إصلاحات. قُرئ DXF النهائي وأُنشئت منه ١٣٣ وجهًا مستويًا في SKP تجريبي وأعيدت قراءتها دون حواف سائبة؛ هذا ليس اختبار استيراد SketchUp Desktop. المعاينة مأخوذة من DXF الفعلي.

الدقة المرجعية محدودة بالصورة، وليست مطابقة مليمترية أو رفعًا مساحيًا. لا يوجد DWG في التسليم لأن محاولات تحويله لم تجتز فحص إعادة القراءة. DXF يفتح مباشرة في AutoCAD ويمكن حفظه DWG باستخدام SAVEAS.

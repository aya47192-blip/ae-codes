# المطعم البوهيمي — نفس بلان SketchUp بصيغة أوتوكاد

[تحميل DWG](Ayaa_Main_Restaurant_Bohemian_Same_Layout.dwg) · [نفس الرسم DXF](Ayaa_Main_Restaurant_Bohemian_Same_Layout.dxf) · [معاينة من ملف DWG بعد إعادة قراءته](AutoCAD_Plan_Readback.png)

بلان 2D مستقل للمطعم الرئيسي، مطابق لمواقع واتجاهات ومقاسات الفرش في نسخة SketchUp المسلّمة. **٣٥ ترابيزة / ١٤٠ مقعدًا**: ١٣٤ كرسيًا منفصلًا وبنشان بإجمالي ٦ مقاعد. وحدات الخدمة والاستقبال والنباتات وديكورات الحوائط والإضاءة موجودة في نفس أماكن الموديل.

كل كرسي وترابيزة وبنش ووحدة كاملة عبارة عن **Block Reference مستقل**. أجزاء القطعة وتفاصيل الترابيزة داخل البلوك نفسه. القطع المتشابهة تشترك في تعريف بلوك واحد، كما في ملف SketchUp، ويمكن تعديل التعريف باستخدام BEDIT. لا توجد أوجه مثلثة أو فرش مفكك إلى خطوط منفصلة في Model Space؛ الرسم فيه مراجع بلوكات كاملة.

الأثاث مسقط علوي مستخرج من هندسة نفس الموديل، والحوايط والزجاج والأعمدة مقطع أفقي عند 1.20 م من نفس عمارة الموديل. رموز فتح الأبواب توضيح تقليدي 2D عند نفس الفتحات. إحداثيات الملف تعود إلى البلان الأصلي بإزاحة X=2190، Y=434، دون إعادة توزيع أو تغيير مقاسات الفرش. الملف الأصلي المرفوع لم يتغير، وهذه نسخة مستقلة للمطعم فقط.

## الطبقات

- `AYAA_BR_CHAIRS` و`AYAA_BR_TABLES` و`AYAA_BR_BANQUETTES`: الفرش.
- `AYAA_BR_SERVICE` و`AYAA_BR_PLANTS`: الخدمة والاستقبال والزرع.
- `AYAA_BR_WALLS` و`AYAA_BR_COLUMNS` و`AYAA_BR_GLAZING`: العمارة.
- `AYAA_BR_WALL_DECOR` و`AYAA_BR_WALL_LIGHTS`: ديكور الحوائط وأباليكها.
- `AYAA_BR_CEILING_LIGHTS`: الإضاءة المعلقة، مخفية/مجمّدة افتراضيًا لوضوح بلان الفرش.
- `AYAA_BR_AISLE_GUIDES`: حدود الممرات التي راجعناها، مخفية/مجمّدة افتراضيًا؛ ليست نقوشًا في الأرضية.

لإظهار الإضاءة أو الممرات افتحي Layer Properties ثم On وThaw للطبقة المطلوبة. حدود الفرش مغلقة وخطوطها Continuous، والأرضية الأساسية بلا نقوش إضافية. المقاسات العددية بوحدات البلان الأصلي؛ لم يُطبّق تحويل وحدات على الفرش.

## الفحص

DWG حقيقي بصيغة AC1018 المتوافقة مع AutoCAD 2004 وما بعده. تمت إعادة قراءته، ومقارنة مراجع البلوكات والهندسة والألوان والمواضع بالـDXF وبيانات SketchUp المسلّمة. فحص DXF والقراءة المرتجعة بلا أخطاء، ومواقع الفرش واتجاهاته محفوظة. أقصى فرق في حدود مسقط الفرش عن الموديل أقل من 0.001 مم.

لم يتوفر AutoCAD Desktop هنا؛ التحقق تم بالقراءة المرتجعة وفحص بنية الرسم والهندسة. [نتائج التحقق](verification.json).

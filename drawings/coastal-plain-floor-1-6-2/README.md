# الساحلي 1.6.2 — أرضية سادة وسجاد منفصل

[تحميل الإكستنشن RBZ](Ayaa_Coastal_Plain_Floor_Separate_Rugs_v1_6_2.rbz)

1. ثبّتي RBZ بدون فك الضغط من **Extensions > Extension Manager > Install Extension**.
2. أعيدي تشغيل SketchUp، وافتحي **File > New**. لا تبني النسخة داخل ملف التلف السابق.
3. **Extensions > Ayaa Coastal 1.6.2 > Build COASTAL - plain floor + separate rugs**.
4. بعد البناء احفظي SKP باسم جديد. البلان و3D في نفس القائمة.

الأرضية الأساسية مستمرة وسادة بلون واحد وبدون نقوش أو خطوط تقسيم زخرفية، بما في ذلك المساحة الموجودة تحت القطع البيضاء. الأشكال البيضاء وحوافها السابقة محفوظة كثلاث قطع مستقلة بسمك 6 مم، كل منها Component منفصل على Tag اسمه **Coastal - Separate Rugs**. يمكن تحريكها أو إخفاؤها من **Show / hide separate rugs**؛ عند إخفائها تظهر الأرضية السادة كاملة. أرضية السنتر البيضاوي ودرجاته كما هي.

أُغلقت فراغات تثبيت الأباليك والبراويز والجداريات، ووُضعت إضاءتا البار على إطاريه الصلبين، وإضاءتا المدخل أعلى البراويز لتجنب التداخل. بقيت جداريّة الموج على نفس الحائط واتجاهها صُحّح لتواجه الجهة الموجودة فيها بدل اختراق الحائط إلى الجاليري. أُضيفت تثبيتات الإضاءات المعلقة، وضُبط استناد إكسسوارات الأرفف. الأشكال والخامات وتوزيع الفرش محفوظة؛ القطع الموجودة بالكامل فوق السجاد رُفعت بسمكه فقط.

استجابة لرسالة التلف، بيانات التصدير تستبعد الأوجه المنهارة والمكررة وتحوّل الأوجه إلى مثلثات مستوية، وتحتفظ بسياقات UV منفصلة دون Explode أو دمج/حذف حواف من شبكة الموديل أثناء البناء. فحوص الأبعاد ومساحة الأرضية محفوظة. هذه احتياطات هندسية، وليست تشخيصًا مؤكدًا لسبب تلف الملف السابق.

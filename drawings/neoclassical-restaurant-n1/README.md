# المطعم — أوبشن نيو كلاسيك N1 / أوتوكاد فقط

[شاهدي PDF المعاينة أولًا — ٩ صفحات](Ayaa_Restaurant_Neoclassical_PREVIEW.pdf)

[تحميل ملفات الأوتوكاد](Ayaa_Restaurant_Neoclassical_AutoCAD.zip)

أوبشن جديد مستقل لنفس المطعم وحدود البلان، بفرش نيو كلاسيك فعلي: كراسي بظهور بيضاوية، ترابيزات رخام مربعة بحواف لينة وبيضاوية بإطارات نحاسية، ركنيات بتنجيد كابيتونيه، وبوفيهات بتفاصيل طولية. درجات أوف وايت وأزرق رمادي ونحاس معتق. البلان يحافظ على الركنيات الثلاث وفتحة الباب داخل الركنية الوسطى، وترابيزات الشخصين والأربعة هي الغالبية.

## المحتويات

- COLOR.dxf: البلان المفروش، ملون للعرض، إصدار DXF R2004، وحداته بالمتر.
- LINEWORK.dxf: نفس البلان والبلوكات بدون تعبئة، للطباعة. زخارف الأرضية مخفية افتراضيًا ويمكن إظهارها من Layers.
- WALL_DETAILS.dxf: ٢٩ تكوين حائط مختلفًا، وواجهات تصميمية مستقلة للكرسي والترابيزة والركنية والبوفيه، وأبليك موحد. هذه واجهات القطع، وليست مساقط حوائط كاملة أو رسومات تصنيع.
- PDF: البلان الملون ونسخة الخطوط، تكبير الركنيات الثلاث، تفاصيل الحوائط، الإضاءة والخامات، وواجهات الفرش. المعاينات مأخوذة من ملفات CAD نفسها، وليست صور رندر.

فكي ZIP أولًا، وافتحي DXF من AutoCAD. يمكنك حفظه DWG من داخل البرنامج. لا يوجد SKP أو إكستنشن في هذه الحزمة.

كل قطعة فرش بلوك مستقل. طبقة **NC_N1_FLOOR_DECOR** تحتوي ١١ بلوك زخارف منفصلًا قابلًا للإخفاء أو الحذف؛ لا توجد زخارف مدمجة بالأرضية الأصلية. الإضاءة السقفية والممرات الإرشادية في طبقات مخفية افتراضيًا. الإحداثيات الأصلية محفوظة بمرجع (2190,434)، والمقاسات بالمتر.

## التوزيع والفحوص

٦٠ ترابيزة / ١٨٦ مقعدًا: ٢٩ ترابيزة لشخصين، و٢٩ لأربعة، وترابيزتان لستة. الممر الرئيسي ١٫٨ م، مع فحص اتصال الحركة الفرعية بعرض يقارب مترًا (٠٫٩٩م). ركنيات L تتبع حدود المثلثات الثلاثة؛ كل ركنية تخدم ترابيزتين منفصلتين لأربعة.

تمت قراءة ملفات DXF بعد التصدير: صفر أخطاء أو إصلاحات. تحققت مواقع واتجاهات ٣٣٨ بلوك فرش وديكور وإضاءة مقابل توزيع المطعم السابق، واختبرت حدود الفرش الجديدة فعليًا: لا تداخلات مسجلة مع الأعمدة والأبواب والممر الرئيسي، ولا مقاعد غير متصلة بمسارات الحركة وفق فحص التقارب المستخدم. حدود العمارة والأبواب محفوظة.

الفحوص برمجية؛ لم يختبر فتح الملفات داخل AutoCAD Desktop هنا. العدد هو مقاعد التصميم، وليس شهادة سعة تشغيلية أو اعتماد مخارج.

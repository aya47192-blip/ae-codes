# قشور السمك — تصحيح العلامات ومساحة الفرط

[الصورة](Fish_Scales_Marked_Fix.png) · [PDF](Fish_Scales_Marked_Fix.pdf)

تعريف المستخدم: «مساحة الفرط» هي المساحة المدمجة عند الجزء السفلي الأيسر فوق الدائرة، بعد إزالة الضلع الفاصل كاملًا عند علامات X البرتقالية وربط الطرفين وفق الخط الأزرق. الأحمر يحدد أخطاء الممرات والجيوب الصغيرة المطلوب تصحيحها.

مقترح مصور للمراجعة لتنفيذ هذه العلامات؛ لا يحتوي CAD ولا يعد تحققًا هندسيًا للمقاسات. النسخة السابقة محفوظة.

لوبي فندق AYAA — الإصدار 3 طبقاً للمرجع الجديد

1. فكّي الضغط بالكامل باستخدام Extract All.
2. افتحي SketchUp بمشروع جديد، ثم File > Import > COLLADA (*.dae).
3. استوردي ayaa_hotel_reference_modern_v3.dae واتركي مجلد textures بجانبه.
4. فعّلي View > Face Style > Shaded with Textures؛ أغلقي Monochrome إن كان مفعلاً.
5. احفظي المشروع بصيغة SKP من SketchUp.

السنتر بيس ودرجتا ارتفاعها وبناء اللوبي وفتحات الأبواب والشبابيك وهندسة الأعمدة مأخوذة من ملف المرجع الجديد دون تغيير إحداثياتها.
الريسبشن والبار في منطقتيهما بالمرجع؛ البار منخفض بلا خلفية عالية.
الخامات والفرش والنباتات والإضاءة جديدة؛ مناطق الجلوس تتبع المرجع مع ترك ممرات أمام الفتحات.
ملف DAE للاستيراد وليس SKP أصلياً. تم فحص الملف وروابط الخامات واتجاه أوجه الأرضيات؛ لم يتوفر SketchUp Desktop لاختبار الفتح فيه.
الوحدات: متر. طبقة تشطيب الأرضية الجديدة 4 مم فوق الأصل، مع الاحتفاظ بسطوح السنتر بيس والدرجات الأصلية.
